Payroll Entry

Use Payroll Entry to record each technician's and salesperson's hours for the week, by store, and to print a Weekly Payroll report.

Before you start: You need the Payroll Entry access right. Without it, Payroll Entry is grayed out on the New menu.

Enter weekly hours

  1. Go to New; Payroll Entry.
    • Weekly Payroll opens on the current week for your store.
  2. To work on another store you have access to, choose it in Location.
    • Week Ending shows the Sunday that ends the week. Weeks run Monday through Sunday. Week shows the week number of the year.
  3. To open a different week, select ... beside Week Ending and pick any date in that week.
  4. Select Add Employee.
  5. Choose Technician or Salesperson, and then select ... to pick the person.
    • For a salesperson, use Look For to filter and Show In-Active User to include inactive users, and then select Done.
    • An employee can be added only once per week.
  6. Enter Work hours, Vacation hours, Holiday hours, Sick hours, Personal hours, Bereavement hours, Jury Duty hours and Salary hours. Total hours adds them up.
  7. If the employee has been terminated, check Terminate.
  8. Select Done.
  9. Select Save.
    • "Weekly Payroll saved successfully!" displays.
    • A week with no employees can't be saved.
  10. Select Print to save and print the Weekly Payroll report.
  11. Select Back to leave.
    • If there are unsaved changes, you are asked to save them first. Select Yes to save or No to discard. The same question displays if you change Location with unsaved changes.

Change or remove an entry

  • Change an entry: double-click the employee's line.
  • Remove an entry: select the delete icon on the line and answer Yes to "Are you sure you want to delete this Payroll item?"

Note: Each store's week is saved separately. Pick the store in Location before entering hours.
