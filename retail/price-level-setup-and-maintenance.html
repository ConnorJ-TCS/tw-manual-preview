Price Level Setup and Maintenance

Use price levels to set default prices by customer, by store, or both. You can create as many levels as you need.

  1. Go to Manage; Company Setup; Pricing.

Add a price level

  1. Select .
  2. Enter a Name.
  3. Select a Parent.
    • This makes another price level the parent. All the parent's price rules are copied to the new level.
    • When the parent price level changes, all its child price levels change too.
  4. Make sure Active is checked. It's checked by default.
  5. Select .

Edit a price level

  1. Select the price level you want to edit.
  2. Make your changes.
  3. Select .

Inactivate a price level

  1. Select the price level you want to inactivate.
  2. Clear the Active box.
  3. Select .
