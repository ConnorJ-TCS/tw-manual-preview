Discount Maintenance

Use the Manage Discounts and Coupons window to set up discount reason codes and coupon campaigns. It has many options so you can fit each discount to your business needs.

Before you start: You need the Company Setup - Discounts and Coupons access right.

To open this window, go to Manage; Company Setup and open Manage Discounts and Coupons.

The General tab of the Discount Reason Codes window holds the options shown here. Use the Discount Reason Codes and Coupon Campaigns radio buttons at the top to choose what you're setting up.

Coupon Campaigns use the same window. Select Coupon Campaigns to set up coupon codes. You can set Allow Duplicate Coupons and a coupon number pattern of Left Characters, Right Characters, Starting Number and Ending Number.

Note: Auto Apply and Buy 3 Get 1 Free are for discounts only.

Discount reason code fields

A new discount reason code needs a Discount Code, a Description, and whether it's Active. The other fields are optional. Hover over the icons in the window to see information about each option.

The optional fields are:

  • Discount Type: Sets a default discount type, Flat Discount or Percent Discount. You can change it when you apply the discount to a Service Request.
  • Amount: Sets a default amount. You can change it when you apply the discount to a Service Request.
  • Start Date & End Date: Set the dates when the discount can be added to a Service Request. The discount can't be added outside that date range.

Note: An order that already has a discount keeps it after the End Date passes, until payment. At Add Payment, TireWorks HD checks the order for expired or inactive discounts and coupons. Users with the Service Request - Expired Discount access right can choose to keep them. For other users they're removed and the order total changes. Check Honor After Expiration to skip this check for the discount.

  • Auto Apply: Check to have the application apply the discount automatically based on the configured Discount Restrictions.

Note: We strongly recommend setting up specific restrictions when you turn on Auto Apply. Otherwise the application applies the discount to every item.

  • Allow Once per Invoice: When checked, the discount reason code can be added to a Service Request only once. A second attempt shows "This discount reason is allowed only once on an invoice. Please edit the already added one OR remove that and add a new one." Auto Apply discounts also honor Allow Once per Invoice when several packages on the order qualify.
  • Buy 3 Get 1 Free: When checked, Discount Type and Amount can't be edited. This option is designed for tires. With or without Restrictions, you can add it only to eligible tires with a quantity of 4 or more. The application calculates the price of a single unit and puts it in the discount amount on the line item.

Note: You can't edit the amount or discount type of a Buy 3 Get 1 Free discount. It's calculated automatically from the tire's unit price, and it applies only when the quantity is 4 or more. If you reduce the quantity, the application removes the discount. If a user hand prices the tire after the discount is applied, the application updates the discount to the correct amount. The FetDiscountable System Setting also affects the amount. When it's True, the calculated discount is Price + FET. When it's False, the calculated discount is Price.

  • Nitrogen Discountable: Sets whether Nitrogen is discountable. This applies to the SKU set up as the Nitrogen SKU code on the Nitrogen Items tab of the Manage; Company Setup; Other Fees and Charges window.

Note: You can't enter negative amounts for discounts and coupons.

  • Minimum Qty: Works only with Inventory or Sku Type restrictions. The discount is split equally across the qualifying line items.
  • Editable on Service Request: When checked, the discount amount and type can be edited on the Service Request. When unchecked, they can't.
  • Per Unit: The discount must be applied to a line item using a Package or Inventory restriction. A flat discount is applied per unit.
  • Class: Discounts and coupons of the same class, or with no class, can be combined. When discounts of different classes qualify on the same package, the one with the largest discount for the customer is applied.
  • Road Hazard Discountable: Sets whether Road Hazard is discountable. This applies to the SKU set up as the Road Hazard SKU code on the Road Hazard Items tab of the Manage; Company Setup; Other Fees and Charges window.

Discount restrictions

Use Discount Restrictions to make a discount eligible only under certain conditions. See the image below, or open the Restrictions in the Manage Discounts window, for the available restrictions.

To set restrictions, open the Manage Discounts window from the Manage; Company Setup menu. The window has two tabs. The General tab is covered in Discount reason code fields above. This section covers how Restrictions work and how to set them up.

Restrictions are completely optional. They give you more control over who, what, where and when the discount can be applied. There are 7 restrictions you can configure: Locations, Sku Types, Customer Classes, Packages, Inventory, Price Level and Customers.

If no restrictions are configured, the discount can be used anywhere, on anything, for anyone. This keeps discounts backward compatible with the discounts functionality in previous versions.

Note: The Restrictions tab has a scroll bar on the right that grows as you expand restrictions. You may see two vertical scroll bars: the outer one moves between restrictions, and the inner one scrolls the options within a restriction. For example, the Inventory restriction shows the whole inventory tree with its own scroll bar, while the outer scroll bar lets you scroll up to the Location restrictions.

Locations

  1. Expand Locations. To show only stores assigned to one region, filter the list by Regions.
  2. Select specific stores, or select Select All, to restrict the discount to those stores.
  3. Select Save so your changes aren't lost.

SKU Types

  1. Expand SKU Types. Use the filter box to find SKU types without scrolling.
  2. Select any or all of the SKU types you want the discount to be eligible on.
  3. Select Save so your changes aren't lost.

Note: With a SKU Type restriction, where you place the discount determines how it's applied. For example, you set up a SKU Type restriction for Tires with a $5 discount. If you add the discount at the Service Request or Package level, it applies to every item of that SKU type: 3 Tire line items get (3) $5 discounts, for a total discount of $15. If you add the same discount to one Tire line item, it results in (1) $5 discount.

Customer Classes

  1. In Customer Classes, select the customer classes eligible for this discount. Use the Look For filter box or Select All.
  2. Select Save so your changes aren't lost.

Packages

The Packages restriction is more complex than selecting an eligible store. You choose not only which package is eligible but also which line items in the package are eligible.

  1. Highlight the package.
  2. To include all of its line items, select Select All.
  3. Select Add.
    • The package and its line items show as eligible in the Configured Packages section, below the list of Packages.

To remove eligibility, use a delete icon in Configured Packages. The icon on the right removes specific line items, and the icon on the left removes the entire package. Select Save so your changes aren't lost.

Inventory

The Inventory restriction shows the inventory tree. You can make an item eligible for the discount in two ways.

  • Inventory Tree: Drill down in the tree, select a tree node or SKU, and select >> to add it to the right side.
  • Search On: Look up items using the available search options.

For example, search for "Passenger" on the "Class" tree level. Then select Select All, or choose the specific passenger classes you want to make eligible.

You can remove items in two ways.

  • Delete icons: Select an item's delete icon to remove that item from the eligible inventory restrictions.
  • Delete button: Click each item you want to remove, then select Delete at the bottom. Confirm the deletion when prompted.

Select Save so your changes aren't lost.

Price Level

The Price Level restriction limits the discount to customers on the price levels you check. Use the Look For filter box or Select All. Select Save so your changes aren't lost.

Customers

The Customers restriction limits the discount to specific customers. Select Search and Add Customer to find and add each customer. To remove one, use the delete icon and confirm when prompted. Select Save so your changes aren't lost.
