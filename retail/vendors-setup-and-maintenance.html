Vendors Setup and Maintenance

Set up vendors in Manage; Company Setup; Vendors. To map brands for replenishment, see Vendor Replenishment. To order electronically, see Vendor Ordering.

  • Vendor Type: Picks the electronic ordering integration the vendor uses, such as Michelin BWS, ATD, TCS Partner or Bridgestone Treadnet. This is set with TCS when the integration is turned on.
  • Active: Clear it to deactivate a vendor. Check it again to reactivate. Requires EDIT on the Vendors - Deactivate/Reactivate access right.
  • Show Inactive Vendors: Check it to include inactive vendors in the list.

Select Save after you make changes.
