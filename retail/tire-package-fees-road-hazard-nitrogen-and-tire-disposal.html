Tire Package Fees (Road Hazard, Nitrogen and Tire Disposal)

Use tire package fees to add Road Hazard, Nitrogen, and Tire Disposal to tire packages, or to record that the customer declined them. Each fee is set up per store and only appears when it's turned on for that store.

Add or decline a fee on an order

Service Requests, Quick Quotes, and Appointments show these buttons on a package that holds a tire:

  • Add RH / Decline RH: Road Hazard.
  • Add N2 / Decline N2: Nitrogen.
  • Add DISP / Decline DISP: Tire Disposal, if your store uses it.

Add adds the store's fee item at its price for the order's price level. Decline adds the store's declined item at $0.00. Decline buttons show only when the store tracks declines for that fee.

Note: The buttons are hidden once the order is completed, and on Goodyear orders. Tire Disposal buttons are also hidden on any special program order, such as TreadNet.

Add fees from the F1 Tire Quote window

On Tire Quote, Include Road Hazard?, Include Nitrogen?, and Include Tire Disposal? add the fee items to packages added from Tire Quote. Nitrogen and Tire Disposal show only when set up for the store.

Note: Whether each box starts checked depends on your store's System Settings, set separately for Quick Quotes and Appointments and for Service Requests.

Order Validation for tire package fees

Order Validation can warn or block when a tire package has neither the fee nor the declined item. Set Road Hazard, Nitrogen, and Tire Disposal to Ignore, Warn, or Block in Manage; Location Setup; Order Validation. See Order Validation.

When validation stops an order, select Fix to use Add Road Hazard / Decline Road Hazard, Add Nitrogen / Decline Nitrogen, or Add Tire Disposal / Decline Tire Disposal.

Note: Road Hazard and Nitrogen are only checked when the store tracks declines for that fee, and they aren't checked on Goodyear orders. Tire Disposal isn't checked on any special program order.

Set up tire package fees

  1. Go to Manage; Company Setup; Other Fees & Charges.
    • The window has Shop Fees, Road Hazard, Nitrogen, and Tire Disposal tabs.
  2. On the fee's tab, select a store from the list.
  3. Under Configuration, check RH Active, N2 Active, or Tire Disposal Active to turn the fee on for the store. Set the other options as needed:
    • Automatically Add ...: Adds the fee on its own.
    • Taxable: Marks the fee as taxable.
    • Use Inventory Tree Mapping: Limits the fee to chosen manufacturers, sub manufacturers, or classes.
    • Track Declined ...: Records declines using the Declined Item you pick. Create Item makes a new item without leaving the window.
  4. In the items grid, select Add New RH Setting, Add New Nitrogen Setting, or Add New DISP Setting to add one setting per price level.
    • Set the SKU Code, a fixed price or a percent of the tire price with Max, Min, and Rounding Cut Off, and the GL Account.
  5. Select Save.

Tip: To reuse a finished setup, select Copy Road Hazard Settings (or the Nitrogen, Tire Disposal, or Shop Fee copy button), pick the stores, and select Copy. Check Overwrite existing metrics at destinations to replace setups those stores already have.

Note: Tire Disposal is turned on through TCS Support. Until then, its tab, buttons, and checkbox don't appear.

Manage packages

Use Manage; Company Setup; Packages to set up the tire and service packages used on orders. Use Look For to find a package by code or name.

  • Show Inactive Packages: Lists inactive packages too. New packages start out Active.
  • Line Item Type: Sets each package item's type, such as a stock item, a Catalog Part, Catalog Labor, or, at Epicor ISE stores, a Catalog Job.
  • Maintain List...: For catalog items, found under Catalog Descriptions. Picks what the catalog should search for. A Catalog Job item holds one job, found by Job Description, Job Code, or Job Category.
  • Program Product Codes...: Sets the Product Code for each special program, plus a Cost Surcharge Code and Quantity Surcharge Code for surcharges.
  • Clone: Copies the selected package as a new package.

Note: A package can't be deleted if it's the Default package, if it's used as an installation package, or if open orders use it. Make it inactive instead.
