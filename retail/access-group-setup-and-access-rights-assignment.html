Access Group Setup and Access Rights Assignment

Use access groups to give users with similar job duties and responsibilities the same access rights.

To open this screen, go to Manage; Company Setup; Access Rights.

Create an access group

  1. Select the Copy Security Profile tab.
  2. In the Profile List, highlight the security profile to copy from.
  3. Enter the new group name in New Profile Name, then select Copy Profile.
    • The message "'[profile]' profile has been successfully copied as '[new name]'." displays.
  4. Select OK.
  5. Select Save .

Set a group's view and edit rights

  1. Select the General tab.
  2. Check the boxes for the view and edit capabilities the group needs in each module.
  3. Select Save .

Set a group's search result fields

The Search Results tab sets the same search result fields for every member of the access group.

Note: You can also manage search result fields at the user level.

  1. On the Search Results tab, select a Search Type from the dropdown.
  2. Highlight the field you want in Available Fields.
  3. Select to move it to Assigned Fields.
    • To move all fields to Assigned Fields, select .
    • To remove a field from Assigned Fields, highlight it and select .
    • To remove all fields from Assigned Fields, select .

After you save access rights

  • When you save, TireWorks HD asks "Would you like to refresh your user session for these changes to take effect?" Select Yes.
    • Other users see the change after Help; Refresh User Session or logging out and back in.

Note: VIEW and EDIT boxes only show where they have an effect for that access right.

Note: Each window under Manage has its own access right. A user sees only the Manage menu items their profile has View for. The Manage menu itself shows only when the profile has View on "Manage All".
