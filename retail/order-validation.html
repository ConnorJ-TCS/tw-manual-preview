Order Validation

Use Order Validation to decide which information users must collect, or are prompted to collect, before a customer is billed out.

  1. Go to Manage; Location Setup; Order Validation.

Set validation conditions

  1. For each Condition, pick IGNORE, WARN or BLOCK under each order state: Quick Quote, Appointment, Estimate, Work Order, Work Complete, Invoice, Declined and Cancelled.
    • Setting WARN or BLOCK at one state also sets it for the states after it. This is typically set at Invoice, so users have time to fill in the information as the order moves along, up until it is invoiced.
    • Conditions are listed alphabetically. Some conditions show only when the feature they belong to is turned on for your company.
    • Ignore: Doesn't require or suggest that the information is collected.
    • Warn: Suggests that the user collect the information, but doesn't require it.
      • Shown by on the service request.
    • Block: Requires the information before invoicing.
      • Shown by on the service request.
  2. Select Save.

Copy order validation to other stores

If you have multiple stores, you can copy your order validation settings to all other stores or to specific ones.

  1. Select Copy Order Validation.

  1. Select in the Filter: Region box and choose Select All.
  2. Clear any stores you don't want to copy to.
  3. Select Copy.

Check order validation on a service request

Order Validation Status is in the top right corner of a service request. It shows the same icons as above, plus when all conditions are met and the order is ready to invoice.

In this window, select the fix icon to fill in the information without going back to find it in the service request.

When you save or invoice, the Order Validation and Prompts window lists anything still open. See Order Prompts.

You can fix blocked validations from this window at the time of invoicing.
