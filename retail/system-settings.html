System Settings

Use System Settings to control how your company and each store behave, including defaults, optional rules and integrations. Many features are turned on here.

Before you start: You need the Manage - System Settings access right.

  1. Go to Manage; Utilities; System Settings.
  2. At Look For, type part of the setting name or its Id to filter the Settings List.
  3. Select the setting to see its Name, Type and Description.
  4. To set it for the whole company, enter the Value under Company Settings Info.
  5. To set it for one store, enter the Value next to that store under Location Settings Info.
    • A store value overrides the company value for that store.
  6. Select Save.
  7. Select Yes at "Would you like to refresh your user session for these changes to take effect?"

Note: Other users, and anyone who selected No, need to select Help; Refresh User Session or log out and back in before the change takes effect for them.

Note: Some settings are managed by TCS and don't appear in the list. Some appear only after the feature they belong to is turned on for your company.

Examples of settings stores commonly use: Transfer Pricing Source, Reorder Point Calculation Method, Inventory Receipt - Populate Quantity Received and Engine Oil Non-Catalog Requires Sourcing.
