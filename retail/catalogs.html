Catalogs

Parts, labor, vehicle, and tire fitment data come from the catalog your store is set up to use. TCS sets up the catalog for each store. What you see on the F1, F2, F4, and F6 screens and on the vehicle screens depends on that catalog. See Catalog Updates for how catalog data is kept current.

Epicor ISE

If your store uses Epicor ISE, parts and labor searches and package resolution use Epicor's online service.

Vehicle Conditions: Epicor may ask questions about the vehicle (for example, engine or transmission details) before it returns parts or labor. The Vehicle Conditions window lists each question with its answers in a list. No answer is picked for you.

  1. Answer each question.
  2. Select Done.
    • The window can't be closed with Esc or the X until the questions are answered.

Note: The same question can come up more than once, because Epicor asks it separately for Parts, Labor, FSM, and Vehicle Specs. The window shows which of these it's asking for.

Catalog Job packages: A package can hold a Catalog Job, which is one Epicor job that includes all the parts and labor for the service. These packages resolve in F2 like any other catalog package.

Note: Catalog Job packages can only be used at Epicor ISE stores. Anywhere else, you see "This package has a Catalog Job item type and cannot be used in non-ISE enabled locations. Please select another package."

F2 pricing: Prices are color-coded.

  • White: Your store's own inventory price, for parts you stock.
  • Yellow: Vendor pricing.
  • Real-time supplier pricing (live supplier cost) and your customer pricing are also told apart by color.

Suppliers: Supplier names come from Epicor ISE. When a supplier has stock at another of its locations, each location is listed on its own line with its quantity. The Supplier Name column shows "[Seller Name] - [Alt. Location Name]".

Missing catalog descriptions

A catalog part or labor item in a package needs catalog descriptions so the catalog can be searched. If a package you pick in F2 has catalog items with none set up, you're asked whether to add the package using the default part and labor items instead.

  • Yes: Adds the package with the default items.
  • No: Cancels. A message explains how to fix the package: in Manage; Company Setup; Packages, select the catalog part or labor item, then select Maintain List... under Catalog Descriptions.

TireGuide

TireGuide provides tire fitment only. If your store uses TireGuide:

  • Adding a vehicle: The fields are Year, Make, Model, and Option. Option is the trim or submodel, not the engine.
  • Vehicle lookup: To look up by plate and state, or by VIN, use the CARFAX QuickVin button. The VIN Lookup button isn't shown.
  • Existing vehicles: Vehicles created under another catalog may need to be opened, updated, and saved again after a store switches to TireGuide.
  • Vehicle information: The Oil Settings, Conditions, and Vin Details tabs aren't shown. Tire fitments show on the Tire Fitment Details tab.
  • Tire fitments: Fitments from TireGuide are saved to the vehicle and used by F1 searches the same way as other catalogs.
  • F4 and F6: F4 Diagnosticator and F6 FSM aren't shown.
  • F2: There are no Parts or Labor tabs. Packages that contain catalog parts or catalog labor are left out of F2 package results.

Add a vehicle during a search

The F1, F2, and F3 screens have an Add Vehicle button. Use it to add a vehicle to the order without closing the search. Fitment is available right away. The button isn't shown on carry-out orders.

  1. To start a quote from a vehicle, select Add Vehicle below Quick Tire Search on the Home screen.
  2. Enter a plate or VIN.
    • A Quick Quote opens with that vehicle, and F1 searches the first tire fitment.

Note: If the plate or VIN matches an existing customer, you're asked whether to use that customer and vehicle, so you don't create a duplicate.

Note: Catalog setup is done by TCS. Contact TCS Support if your store's catalog needs to change.
