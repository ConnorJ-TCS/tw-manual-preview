Bridgestone Firestone National Accounts (TreadNet)

Use Bridgestone Firestone National Accounts to send an order's delivery receipt (DR) to Bridgestone's TreadNet system. If your store is set up for it, TireWorks HD builds the DR, sends it to TreadNet, then brings the TreadNet invoice back into TireWorks HD. This works like Goodyear National Accounts, but with its own screens.

Start a national account order

  1. Create the service request as usual.
  2. Select the Bridgestone special program for the customer.
  3. When the order is linked to a TreadNet program, the TreadNet button shows above the packages and line items. Select TreadNet to open Bridgestone Firestone National Account.
    • If no fleet or dealer is assigned yet, the Bridgestone Firestone National Account Selector opens.
  4. Answer the Billed Customer Questions: Is this a Dealer-to-Dealer transaction? Is this Delivery Receipt for a customer billed locally? Does this Delivery Receipt contains an Off-The-Road (OTR) tire(s) or service(s)? Was this a tire(s) only sale? Was the service done on specific vehicle?
    • The answers set the DR Type. Changing an answer later restarts the delivery receipt.
  5. Search by Fleet Id (or Dealer Id), Name, Address, or City.
  6. Select the account, then select Done.

Requirements, Submission, and Status tabs

  • General: Shows the Customer Name, Customer Id, and DR Type. Select the fleet link to change it.
  • Requirements: Lists what TreadNet needs for this fleet and DR Type. Required items are marked with *, and the Validation and Status columns show what's still missing. Some requirements appear or become required based on earlier answers.
  • Tire line details: For some DR Types, tire lines also need Wheel Position, Barcode, OTR Serial Number, or Removed Tire DoT Number. You enter these with the DOT number, and required fields show a red asterisk.
  • Submission: Shows DR Submission, a summary of what will be sent, with any warnings or errors that block it. Select Submit DR when it's clear.
  • Status: Shows TreadNet DR Status, including Current Status, Web DR Number, TreadNet Invoice Number, and Message. Select Fetch Current Status to refresh, or View Invoice once the invoice arrives.

After Submission

Once the DR is submitted, the order is locked and can only be viewed until TreadNet invoices it. Then you can invoice it in TireWorks HD. Users with the Bridgestone NA - Edit Order Before DR is Invoiced access right can still edit and invoice the order.

If TreadNet rejects the DR or needs dealer action, the order becomes editable again so you can correct it and resubmit.

The TreadNet invoice PDF is collected automatically after invoicing. Open it from the Status tab, or from the vendor credit for the order during program reconciliation.

Tip: Use the Home screen filter to find orders by TreadNet DR Number or Web DR Number.

Note: On TreadNet orders, Prod. Code drops leading zeros from tire part numbers to match Bridgestone's invoice format.

Set up DR# sequences

  1. Go to Manage; Special Programs; Manage Special Programs.
  2. Select the TreadNet program, then open the DR# Sequence tab.
  3. Enter a DR Number Sequence for each location to number new orders automatically. Leave it blank to type the DR# on each order.

Note: Only users with the Bridgestone NA - Override Auto DR Numbers access right can change an automatic DR#.

Program reconciliation

Before you start: You need the Special Programs - Manage Program Reconciliation and Special Programs - View Program Reconciliation Transactions access rights.

Manage; Special Programs; Manage Program Reconciliation sets up how a special program's orders are reconciled. You choose whether to add transactions to the reconciliation window, whether to automate the customer credit invoice and vendor credits, the variance threshold (dollar or percent), the vendor, and the credit, misc, commission, and variance SKUs. Link Invoice PDF To AP Invoice attaches the TreadNet PDF to the vendor credit.

Assign programs on the Program Association tab.

Manage; Special Programs; View Program Reconciliation Transactions lists each order's transactions. Search by Special Program, Reconciliation Status (All, All Incomplete, Open, Submitted, Needs Review, Completed), Dates, and fields such as DR Number, Order Id, or Vendor Invoice Id.

  • Line status: Mark lines Submitted, Review Needed, or Completed, and review Commission, Gain/Loss, and Variance.
  • Create AP Invoice: Creates an AP invoice linked to the order. Requires the Special Programs - Reconcile - New AP Invoice access right.
