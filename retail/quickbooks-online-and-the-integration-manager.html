QuickBooks Online and the Integration Manager

When your company uses QuickBooks Online (QBO), TireWorks HD sends your invoices, returns, customer payments, customer deposits, vendor bills, inventory receipts, and inventory adjustments to QBO. Customers, vendors, GL accounts, tax details, payment terms, payment types, credit cards, and customer classes are kept in step between the two systems.

Note: TCS connects TireWorks HD to your QBO company and turns on the Integration Manager during setup. Contact TCS Support for the first connection, or if QBO asks you to sign in again and you don't have access to finish it.

Where accounting errors show up

Closing an invoice no longer stops to show an accounting error. The invoice closes and prints as normal. If the invoice did not reach QBO, it waits in Integration Manager with the reason attached.

Note: Check Integration Manager daily so nothing sits unposted.

Check sync status

  1. Go to Manage; Utilities; Accounting Integration.
  2. Select the Integration Manager tab.
  3. Check the stores to review, or check All Locations.
  4. Check the document types to review, or check All DocumentTypes.
    • The list shows every document that has not integrated yet, with Location, Doc Type, Doc Number, In Process, Trans Date and Last Attempt.
    • Total Items shows how many are waiting.
  5. Select the refresh icon to reload the list.

Note: Integration Manager remembers the stores and document types you picked last time.

Fix a failed item

  1. Double-click the document, or right-click it and select View Messages, to read why it failed.
  2. Correct the cause. Common causes are a customer class, item or account that is missing in QBO, or a record in QBO that is missing required information.
  3. Select the document and select Re-Integrate Selection.
    • Use Ctrl + Click to pick several documents, Shift + Click for a range, or Ctrl + A for all.
  4. If you made the fix to the TireWorks HD record itself, select Rebuild And Re-Integrate Selection instead.
    • This rebuilds the accounting data from the document before sending it again.
    • Select Yes at "Do you really want to rebuild the accounting data before re-integrating the selected documents?"
    • Requires the Accounting Integration - Rebuild XML access right.

Note: If a document shows In Process and never finishes, right-click it and select Reset In Progress flag, and then re-integrate it.

Note: TireWorks HD checks QBO for an existing inventory receipt, adjustment or AP invoice with the same document number before sending, so re-integrating doesn't create a duplicate.

Sync records with QBO

Use Sync Items to pull setup records from QBO, or push records to QBO, on demand.

  1. Select the Integration tab, and then Sync Items.
  2. At Sync Direction, select Receive (from QBO) or Send (to QBO).
  3. At Items To Sync, select the record type: Credit Cards, Customer Classes, Customers, GL Accounts, Payment Terms, Payment Types, Tax Schedules or Vendors.
    • Send lists only the record types turned on under Integration Options on the General tab.
  4. To only link unmatched records and create missing ones, check Sync Unsynced Items Only (No Updates). Uncheck it to also update records that are already linked. This can take a long time.
  5. Select Receive Items or Send Items.
  6. Review the Log. To copy the log for Support, select the copy icon.

Note: A QBO record missing required information is skipped, and the log names it. Complete the record in QBO and sync again.

Set up tax variance alerts

TireWorks HD can compare the tax QBO calculates on a posted invoice with the tax TireWorks HD calculated, and alert you when they differ. The invoice still posts. The alert is for review.

  1. Select the General tab and go to Tax Variance Alerts.
  2. Check Enable Tax Variance Alerts.
  3. Enter a Dollar Variance Threshold, a Percent Variance Threshold, or both. Going over either one creates an alert.
  4. Select Save.

Note: You can't save with the alerts turned on and both thresholds blank.

Review integration alerts

Before you start: The Integration Alerts tab appears only after Tax Variance Alerts is turned on.

  1. Select the Integration Alerts tab. A red count on the tab shows unread alerts.
  2. Filter by Location and Document Type if needed.
    • The grid shows Location, Doc. Type, Doc. Number, Txn Tax Details, Alert Message and Date/Time.
  3. Select one or more alerts and select Mark as read. You don't need to save.

Screens that work differently with QBO

  • GL Account: Display only. Add or change GL accounts in QBO, and then receive them on Sync Items.
  • Customer Maintenance: The Financial Summary tab isn't shown.
  • Manage Tax Details: You must select a Tax Agency before you can save a new tax detail. After the first save, Tax Detail ID, Tax Agency, Tax Detail Type and Tax Detail Percent can't be changed.
  • Manage Locations, Accounting tab: Choose the Location Refund Account from the list. Fields that don't apply to QBO are hidden.
  • Customers and vendors: Appear in QBO as NAME (ID), so two with the same name stay separate.
