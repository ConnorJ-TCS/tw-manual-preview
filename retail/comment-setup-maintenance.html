Comment Setup & Maintenance

Use comment setup to create the comments your stores use often, group them, and assign them by store.

To open this screen, go to Manage; Company Setup; Comments.

Add a comment

  1. Select the Comments tab.
  2. Select Add .
  3. In Comment Code, enter the comment abbreviation.
  4. In Comment, enter the comment description that appears on the service request.
  5. Select the Specification Type/Service Type.
  6. Make sure Active is checked.
  7. Select Save .

Inactivate a comment

Comments can't be deleted, only inactivated.

  1. Highlight the comment and clear the Active box.
  2. Select Save .

Edit a comment

  1. Highlight the comment and edit the information.
  2. Select Save .

Note: By default, only active comments display in the comment list. Select to view all comments.

Add a comment group

  1. Select the Comment Groupings tab.
  2. Select Add .
  3. In Comment Group Code, enter the group name.
  4. Enter the Comment Group Description.
  5. Select and select a comment from the list.
    • Repeat until you have added all the comments.
  6. Select Save .

Edit a comment group

Note: You can't inactivate a comment group today. Instead, we suggest changing its Comment Group Code to DO NOT USE.

  1. Highlight the comment group and edit the information.
  2. Select Save .

Remove a comment from a group

  1. In the Comments list, highlight the comment to delete.
  2. Select Delete .
  3. Select Save .
