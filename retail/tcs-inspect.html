TCS Inspect

Use TCS Inspect, the tablet inspection app, to bring vehicle inspections into TireWorks HD. There you can link them to orders, review photos and videos, and send the results to the customer.

Before you start: TCS Inspect setup is done with TCS and is found at Manage; Company Setup; TCS Inspect Configuration.

Inspections tab (Home screen)

The Inspections tab lists inspections for the selected Dates, with Id#, Date Created, Procedure, Vehicle, Mileage, and Linked Order.

  • Show Unlinked Inspections Only: Shows inspections not yet attached to an order. Depending on your store's setup, the tab may be highlighted when unlinked inspections are waiting.
  • Filter: Searches by Id, vehicle name, or order Id.
  • View Inspection: Opens the selected inspection. You can also double-click an inspection to open it.

Link an inspection to an order

  1. On the Inspections tab, select Link To Service Request.
    • The Link TCS Inspection window lists orders at your store for the same VIN.
  2. Select the order, then select Link.
  3. Select Yes to confirm.

Tip: To start a new order instead, select Create a new Service Request. The VIN and mileage carry over.

Note: You can also link from a vehicle's Inspections tab inside a Service Request. There, Link To Service Request links to that order. Save the order first.

Select Open Linked Service Request to open the order, or Unlink from Service Request to remove the link.

Note: An inspection can only be linked to one order. Copying a Service Request doesn't copy its inspections.

Inspections on the Service Request

On the Home screen Service Request list, a TCS Inspect icon with a red count shows inspections on that order that haven't been viewed yet. The count clears once the inspection is opened.

On the Service Request, select the TCS Inspect icon to see TCS Inspect Report(s), then select one to open it. To copy the customer's live feed link, select Copy TCS Inspect Live Feed Url.

TCS Inspect Recommendations shows the recommended items from the inspection that can be added to the order.

Note: Technicians can submit inspections while the order is open in TireWorks HD. Reopen the order to see the new data.

Inspection detail

The header shows Inspection Id, Procedure, Order Id, Created At, Inspection Started, Inspection Submitted, Total Inspection Time, Vehicle, VIN, Mileage, Marked 'All Okay', App Type, License, State, and Related Inspections.

Note: A warning icon means the vehicle information may have changed since the inspection.

The services list shows each service with Comments, Active, Media, and Detail.

  • Media: Select the icon to view all photos and videos for that service. Scroll to see each one.
  • View Tire Data Attributes and View Brake Data Attributes: Show the Tire Measurements and Brakes Measurements.

Use the buttons at the bottom of the window to share the inspection:

  • Print: Prints the inspection report.
  • Email: Emails the inspection report.
  • Send Text: Opens a text with the inspection report link.
  • Text Live Feed URL: Opens a text with the customer's live feed link. The inspection must be linked to an order that has a live feed.

Print the inspection with the invoice

To print the inspection report automatically when the order is invoiced, set up a document at Manage; Company Setup; Auto Print Documents with Document Source Type set to Inspection. Every inspection linked to the order then prints along with the invoice.
