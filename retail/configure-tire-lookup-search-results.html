Configure tire lookup search results

Use Search Results Configuration to choose what shows on your search results screen. Each user can set up their own search results.

Open Search Results Configuration

  1. In the F1 Tire Lookup search screen, right-click any line item and select Configure Search Results.
    • The Search Results Configuration window opens for the list you right-clicked.

Tip: Right-click works the same way on other lists that support it, such as the Home screen tabs.

Note: A user with the Search Results Configuration - User Selection access right can pick another user at the top right and set up that user's results.

Note: Managers can also open this window at Manage; Location Setup; Search Results Configuration.

Add search fields

  1. Verify that Search Type is set to Tire Lookup.
  2. In the Available Fields list, highlight the field you want to show in the search results, and then select .
    • The field moves to Assigned Fields.
  3. Repeat until every field you want has been moved to Assigned Fields.
  4. Use the arrows to arrange the fields in the order they display, from left to right.

Add sort columns

  1. Follow the same steps to add Sort Columns.
    • At least one sort column is needed to save.
  2. Select .
  3. Select Save.

Note: If the changes do not show right away, select Help; Refresh User Session.
