Sign in

Use the Login screen to sign in to TireWorks HD and choose the store you work in.

Sign in with a TireWorks HD account

  1. Enter your User Name. The user name is not case sensitive.
  2. Enter your Password. The password is case sensitive.

  1. Select the store you want from the list of available locations.
    • Use the search box to find a store by location number or location name.
    • If you have access to only one store, TireWorks HD logs you directly into that store.
  2. If your store uses iPOSPays, select a credit card terminal when you are asked, after you pick the store. See Electronic Payments.

Sign in with your Windows account

Before you start: A manager must first map your Windows account to your TireWorks HD user at Manage; Company Setup; Users, on the Windows Authentication tab.

  1. Select Windows Authentication instead of TireWorks HD Authentication.
    • User Name fills in with your Windows login. Password is not used.
  2. Select Login.
