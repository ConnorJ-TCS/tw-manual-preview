Item Group Setup and Item Assignment

Use item groups to display inventory by group in a general search. You can give each group a color and rank the groups in display order. You set groups up once, and they cover all stores.

  1. Go to Manage; Inventory; Item Group.

Create an item group

  1. Select Add .
  2. On the Item Group Details tab, enter the Item Group Name.
  3. Enter a Description.
  4. Select a Start Date from the calendar .
  5. If you want one, select an End Date from the calendar .
  6. Select a color for the group's items to display in.
  7. Turn Set Priority as Nothing on or off as needed.
  8. Turn Show Always on or off as needed.
  9. Select Save . "Successfully Saved" displays.
    • The group now displays in the Item Group List.

Add SKUs on the Sku ItemGroup Mapping tab

The Sku ItemGroup Mapping tab lists the SKUs in the selected group and lets you add SKUs to it.

  1. In Search Item to Add, enter at least three characters of the SKU and select Search.
    • If more than one item matches, select the item from the list.
    • To create a new SKU, select Create Item. This requires the Inventory Management access right.
  2. Select Save.

Note: You can also add items to a group from Manage Inventory. See Add items to a group below.

Rank item groups

  1. Select a group and use to move it into the display order you want.

Add items to a group

  1. Go to Manage; Inventory; Manage Inventory.

  1. Enter the Manufacturer Item Number , select the SKU from the results list, and select OK.
  2. On the Item Detail tab, select the group from the dropdown shown below.

  1. Select Save . "Successfully Saved" displays.
