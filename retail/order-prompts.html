Order Prompts

Use Order Prompts to have TireWorks HD ask your own questions on a Quick Quote, Appointment, or Service Request. You choose the order states and actions that ask each question, the answer type, and whether an answer is required.

Set up an order prompt

Before you start: You need the Access Right "Manage - Order Prompts".

  1. Go to Manage; Location Setup; Order Prompts.
  2. Select Add Prompt.
  3. Under Order States, check each state that should ask the question: Quick Quote, Appointment, Open, Estimate, Work Order, Invoice, Declined, or Cancelled.
  4. For each checked state, pick Prompt When: Order is Saved, Customer is Assigned to the Order, or Vehicle is Assigned to the Order.
    • Declined and Cancelled always ask when the order is saved.
  5. In Required:, pick the first state where an answer is required, or Not Required.
    • That state and every state after it require an answer.
  6. Under Question and Answers, enter the Question:.
  7. Pick the Answer Type:: Alphanumeric, True False, List With Single Select, or List With Multi Select.
    • For a list, enter each choice in Answer: and select Add.
  8. Select Done, or Add Another to start the next prompt.
    • Answer Yes to "Do you want to make the prompt Active?" to start using it.
  9. Save the screen.

Tip: Use Copy Order Prompts to copy saved prompts to other stores.

Important: Changing the answer type clears the answers you already entered for that prompt.

Answer prompts on an order

When a prompt's state and action are reached, the Answer the following questions window opens.

  1. Answer each question.
  2. Select Done.
    • A * marks a required prompt. You can't continue until every required prompt is answered.

Tip: Check Show Previous Prompts to see questions from earlier order states.

Note: The System Setting "Order Prompts - Show Previous Prompts by Default" makes Show Previous Prompts checked each time the window opens.

Order Validation and Prompts window

When you save or invoice an order, the Order Validation and Prompts window lists open validations, and any unanswered prompts under Prompts.

  • Answer: Select it next to a prompt to answer that prompt.
  • Show Prompts: Review or change prompt answers, even when none are pending.

Note: An order with an unanswered required prompt can't be saved or invoiced.
