Create a part

Use Create Part to create and manage items you order through outside purchase, such as original equipment parts. These parts become inventoried items and are priced by the price rules of the branch the item is placed in.

  1. Select Item Lookup .

  1. Search for the part number to make sure it isn't already in inventory management.
  2. Select Create Part .

    • Manufacturer is fixed to Parts, Labor & Service.
    • Sub-manufacturer through Sub-category come in with defaults, but you can choose others.

Important: These selections decide where the item is created in the inventory tree, which drives pricing and GL posting in QB.

  1. Select Next.

  1. Enter the original equipment item number.
    • The item number copies into the description automatically. Overwrite it with the description you want.
  2. Enter the Cost. This cost passes to the service request, PO, receipt and AP invoice.
  3. Enter the Price. It defaults above cost until you overwrite it.
  4. Enter the Quantity.
  5. If there are multiple packages on the order, select the package to add the item to.
  6. Select Create Part .
    • The part is added to the order automatically, with a sourcing icon.

  1. Source and receive the part as usual.

Note: This process creates the item in the right branch of the inventory master file. Because it is an inventoried item, it now shows on the unsold purchases report, and you can either return an unsold item or put it away. Returning it creates a credit AP invoice.
