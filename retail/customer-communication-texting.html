Customer Communication (Texting)

Use two-way texting to text customers from TireWorks HD. Customers can reply to your texts, and their replies come back into TireWorks HD. Every text, email, and call note for a customer is kept together in Customer Communication.

Contacts that can receive texts

You can text a customer at any contact with Contact Type Text, or Contact Type Phone or Phone 2 with Phone Type Cell. To add one, enter the number in the customer's Contact Info and select Add.

Note: Cell Provider isn't needed for two-way texting and is hidden when two-way texting is on. It only shows for stores still set up for the older one-way (email-to-text) method.

SMS Hub (Home screen)

The SMS Hub icon sits at the top right of the Home screen. A red balloon shows the number of unread messages. Over 99 shows "99+". New messages are checked about every 60 seconds by default.

  1. Select the SMS Hub icon to open the SMS list of unread messages.
    • Each message shows the customer name (or "Anonymous" if the number isn't on file), phone number, time, vehicle, and message.

From the list, you can:

  • Order icon: Opens that order.
  • Read icon: Marks the message with Mark as Read or Mark as Unread.
  • Double-click a message: Opens the conversation so you can reply.

Note: The SMS Hub also receives alerts from TireWorks HD itself, such as a new appointment or quote booked online, auto-replenishment results, a failed TCS Inspect submission, or a customer's remote authorization.

Note: The SMS Hub isn't available while your session is locked.

Send a text

  1. Open the conversation from one of these places:
    • On a Service Request, select Send Text (the Customer Texts icon). A red count shows unread replies.
    • On the Home screen Service Request and Quick Quote lists, hover over an order and select the Customer Texts icon.
    • From the Appointment and Quick Quote windows.
  2. Choose the number from the drop-down under the customer name.
    • From a Service Request, the list defaults to the primary contact of the member on the order and shows only that member's numbers, plus any address contacts marked Cell.
  3. Type the message.
    • Messages can be up to 1600 characters. The counter below the box shows the characters used.
  4. Select Send.

Note: Emojis sent by customers display in the conversation.

Tip: Use Find at the top of the conversation to search the messages.

Set up canned messages

  1. Go to Manage; Company Setup; Canned Text Messages.
  2. Enter a Message Code, Message Title, Message, and Message Category.
  3. Use Apply To... to choose which locations can use the message.

Use canned messages and placeholders

To use a canned message, open Canned Messages on the left of the text window and double-click a message, or pick one from Quick Add Template. Most Popular lists the 10 most used messages at your store.

Placeholders fill in customer, order, vehicle, and store details for you. They work in typed messages and in canned messages. To add one, open Placeholder on the right and double-click one, or type # to see suggestions.

Examples include #CustFirstName, #OrderId, #OrderTotal, #VehicleDesc, #LocationPhone, #InspLiveFeed, #PromiseDT (promise date and time), and #ApptDateTime (earliest appointment date and time on the order).

Note: Use of canned messages and placeholders is controlled by the Canned Text Messages access rights.

Customer Communication screen

Use the Customer Communication screen to see a customer's messages and call notes in one place. Open it from the Communication button on a Service Request, the View Customer Communication icon on the Home screen lists, or the Communication tab in Customer Maintenance.

The list shows emails, call notes, texts, Text-to-Pay, and Text-to-Auth messages, with Status, Location, Type, Direction, Date, Reference, Contact, and Subject/Message.

  • Filters: Filter the list with Dates (Last 7 Days by default), Include All Locations, the type check boxes, Show, and Look For.
  • Show: Limits the list to InBound (Internal), OutBound (Internal), Inbound (External), or Outbound (External). Internal is a message sent or received through TireWorks HD. External is a message from your Cinch messaging service, if your company uses Cinch.
  • Magnifier: Opens a message so you can read it. The message is then marked as read.
  • Call Note: Enter a note and select Save.
  • Send Text: Type a message, choose the number in To, and select Send Text.
