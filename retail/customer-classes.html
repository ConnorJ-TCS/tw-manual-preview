Customer classes

Use customer classes to give a group of customers the same defaults, such as discount percent, tax, shipping method, terms and price level.

To open this screen, go to Manage; Company Setup; Customer Class.

Add a customer class

  1. Select Add .
  2. Under Basic Information, enter the Class ID.
  3. Enter the Description.
  4. Under Financial Information, enter a Discount Percent if you want one.
  5. Under Personal Shipping Info, select a Tax ID from the dropdown.
    • We suggest leaving it blank so sales tax is based on the store performing the service.
  6. Select the Shipping Method from the dropdown.
    • This is generally the Will-Call/Pickup method.
  7. Select the Terms Code.
    • This is generally CASH SALES.
  8. Select the Department code if you use one.
  9. Select the Price Level.
  10. Review the checkboxes and change them if needed.
    • PO Required is unchecked by default.
    • Active is checked by default.
    • Tire Tax Exempt is unchecked by default. We suggest checking it for National Account classes.
  11. Select Save .

Edit a customer class

  1. Highlight the customer class.
  2. Make your changes.
  3. Select Save .
