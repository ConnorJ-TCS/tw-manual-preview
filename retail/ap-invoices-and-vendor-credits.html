AP Invoices and Vendor Credits

An AP invoice records what your store owes a vendor for product received. A vendor credit is an AP invoice for a return, recording what the vendor owes you back. Both open in the same AP Invoice window.

When AP invoices are created

  • By default, TireWorks HD creates the AP invoice for you when an inventory receipt is processed, and the vendor credit when a return is processed.
  • If your company turns on the System Setting Disable Automatic AP Invoice Generation, no AP invoice or vendor credit is created automatically. Create them yourself with New; AP Invoice or the Vendor Credit button. See Two-Step Returns below.

Create an AP invoice

  1. Go to New; AP Invoice.
  2. In the vendor selection window, which opens right away, search with Look For, highlight the vendor, and select Done.
    • You can create an AP invoice for any vendor, not only preferred vendors.
  3. Enter the vendor's invoice number in Reference. A Reference is required before the invoice can be processed.
    • You're alerted if the same reference number was already used for this vendor.
  4. Add lines:
    • Receipt Items: Opens Add Inventory Receipt Items. Filter by PO # or Item #, check the received items to bill, and add them. Receipt Cost and Variance show how the invoice cost compares to what was received.
    • Add Items: Search for and add items directly.
  5. Verify the Payment terms, Tax Rate and Discount %.
  6. Enter Freight if the vendor charged it. Freight entered on the purchase order carries to the receipt and the AP invoice.
    • Editing Freight requires the AP Invoice - Edit Freight Amount access right.
  7. Select Save to keep working later, or Process to finalize.

Important: A processed AP invoice can no longer be edited.

Other AP invoice actions

  • Payment: Records a payment against the invoice. Enter the Payment Type, Payment Amount and Comments, then select Apply and Done.
  • Cancel: Cancels the AP invoice after you confirm.

Find an AP invoice

  1. Go to Find; AP Invoice.
  2. Search by Invoice Id, Vendor (or All), Dates and Status (All, Open, Processed, Cancelled).
    • Results show the Reference No., Create Date, Invoiced Date and Accounting Integration status. Open or print from the result line.

Two-Step Returns

If your company uses two-step returns, you can start a return from the original purchase order or receipt, then create the vendor credit as a separate step.

  • Return: Displays on fully or partially received purchase orders (the Purchase Order window, Find; Purchase Order, and the Home screen Purchases tab) and on processed inventory receipts (the Inventory Receipt window and Find; Inventory Receipt).
    • Return on a purchase order creates a return purchase order. Return on a receipt creates a return inventory receipt and opens it for review.
    • A document can only be returned once, and a return can't itself be returned.
  • Vendor Credit: Displays on the return inventory receipt once it's processed. Select it and confirm to create the vendor credit, which opens in the AP Invoice window.

Note: These buttons require the Two Step Return Process - Return Button and Two Step Return Process - Credit Button access rights.

Note: The Inventory Returns - Two-Step Workflow setting only adds the Return and Vendor Credit buttons. It doesn't change New Return or Unsold Purchases Create Return, which still create and process the return purchase order and return inventory receipt in one step. Whether the vendor credit is created automatically depends only on Disable Automatic AP Invoice Generation.

Link Bridgestone (TreadNet) invoices

If your store orders from a Bridgestone TreadNet vendor, a Link Bridgestone Invoice button displays on that vendor's AP invoices.

  1. Select Link Bridgestone Invoice. Unlinked Bridgestone Invoices opens, listing Invoice Date, Invoice No. and Invoice Total.
  2. Select View to preview the PDF.
  3. Select Link Invoice.
    • Once an invoice PDF is linked, View National Account Invoice opens it.
