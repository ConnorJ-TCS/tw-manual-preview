Unlocking Objects

Used to unlock orders, invoices, receipts and purchase orders when warning displays that it is locked by another user. This function can be added to any access group by selecting the appropriate access group and looking for UNLOCK OBJECTS module and check the appropriate boxes for view and/or edit. Generally, however, setting or altering access rights is a function of the Administrator access group.

At Home Screen: Select Administration from module tool bar

Select Unlock Objects

  • Display will appear with all records that are locked by order type

  • Highlight appropriate object to unlock
    • Can select multiple line items by holding the CTRL key and clicking on each line item you wish to unlock
  • Select Unlock
    • If Multiple selection made, it will ask you if you are sure you want to unlock (total number of line items selected)
      • Select Yes to move forward
      • Select No to go back and reselect line items
  • Select OK
