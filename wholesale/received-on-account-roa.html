Received On Account (ROA)

Select from application toolbar, Select from dropdown

  • Enter known search criteria
    • Check, Filter for current location if needed
  • Select Search
  • Highlight desired customer
  • Select OK

  • Select
  • Enter Payment information (If check, check number required, if credit card, select card type).

  • Displays payment in payment box

  • Select open invoices for application (If company procedure)
    • If company procedure is to not apply just take payment, DO NOT select invoices for application
  • Select
    • Dialog box will appear if not application, verifying nothing applied, requesting approval to continue
  • Receipt for ROA will display for printing
  • Exit ROA screen
