User Setup & Maintenance

Users and Salespersons are created via user setup.

From Home Screen, Select

New User

Select

General Tab

    • Enter UserID (generally first initial last name)
    • Enter Name
    • Enter desired password
    • Enter email address
    • Verify Active status is checked (checked by default when new user is selected)
    • Toggle “Is Salesperson” (checked by default when new user is selected)
    • Select Commission Program user will be associated with
    • Toggle “Use Default Customer on Sales Order” if desired (unchecked by default when new customer is selected). Recommend not checking box
    • Select appropriate locations user will be working from
    • Select the appropriate security profile from drop down box

Pricing Tab

  • Select approved price level(s) for user from price level list and selectto move them to Assigned price levels list
      • If Multiple levels, select first one and hold CTRL key and make the rest of the selections
      • If All levels, select upper most level and hold SHIFT key and select bottom level
    • Toggle “Allow hand pricing” on if desired (Will override access rights assigned to user)
    • Toggle “Enforce minimum profit % and enter percentage
    • Toggle “Enforce maximum markdown % and enter percentage

Auditing Tab

Select ALL in the auditing tab for each location assigned

Salesperson Tab

Enter salesperson’s names if tied to a specific user/salesperson

User Maintenance

Inactivate User

    • Uncheck active status in general tab (lists all active and inactive users)
    • when complete

Reset Password

  • Back out old and enter new – Case sensitive (no second verification required)
  • when complete

Remove Price Levels

  • Select approved price level(s) for removal from Assigned Price Level list and selectto move them to Price levels list
      • If Multiple levels, select first one and hold CTRL key and make the rest of the selections
      • If All levels, select upper most level and hold SHIFT key and select bottom level
  • when complete
