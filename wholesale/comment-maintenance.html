Comment Maintenance

Remove Comments

  • Highlight desired comment and uncheck active box
    • Automatically removes from Comment Groupings
  • Select
  • Select to view list of inactive comments
    • Checking active box will reactivate and display on back on list
    • Will automatically add back to Comment Groupings

Delete comments from Comment Grouping

  • Highlight line to delete in comments field and selecting
  • Select

***Note:*Cannot delete or inactivate a Comment Grouping.

Changing Location Grouping assigned to a location

  • Select desired grouping from dropdown of location to be changed

Removing Grouping from location

  • select next to dropdown of location desiring to clear
