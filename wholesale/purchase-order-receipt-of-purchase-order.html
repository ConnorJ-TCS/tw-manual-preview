Purchase Order & Receipt of Purchase Order

Home Screen: Select then select from start a task

Create Purchase Order

  • Select Vendor from dropdown
    • Vendor information defaults from vendor master
  • Populate Reference (required)
  • Populate delivery date if known
    • Select plus to select from calendar
    • Select X to remove date previously populated
  • Select - Searching same as sales order searching

    • Optional checkbox for Available items only
    • Optional Checkbox for Discontinued items only
      • Discontinued items are set in item master record and display in red
    • Global Lookup: Enter search criteria
      • Universal Sku: simple tire size, three-digit mfg. abbreviation, and mfg. item number (i.e. 2056515GOO402406477)
      • Searchable by all or any combination of Universal Sku
    • Description Filter: Used to narrow search results based on description
      • i.e. line of tire, speed rating, etc.)
      • When description filter is removed goes back to original search results
    • User SKU Code Lookup: Another lookup based on what is populated in User SKU field in item record
    • Optional checkbox to display winter tires only
    • Use Inventory Tree Lookups: Can be used to search by inventory tree nodes
  • Select items to add to order
    • Search results display by largest quantity available
    • Search results display with manufacturer invoice price
  • Enter quantity of desired item and enter. Will move selected item to cart below search screen and return to Global Lookup for next item search

Note: ALL search columns are sortable by clicking column header to sort in ascending order. Click again will go back to descending order.

  • Select when all items have been added
  • Items will be populated in purchase order
  • Add comments in desired
  • Select Save
  • Dialog box appears showing successful save
  • Purchase order is assigned next sequential number by location
  • Printable, importable and exportable depending on need
  • Save and close when complete

Receipt of Purchase Order

  • Reopen original purchase order when product has arrived
  • Select
  • Inventory Receipt will generate within purchase order
  • If WMS is NOT used, proceed to process step below
  • If WMS is used, Select Send to WMS
  • Once WMS has received and transmitted received quantity back to receipt, Select
  • Selectto received product
  • Select desired process type (default process as is) and Continue Processing

  • Inventory receipt will display for printing
  • Follow company procedures
  • Inventory status will have status of processed and inventory will be updated in POS
