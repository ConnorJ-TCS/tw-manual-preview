Access Group Setup & Access Rights Assignment

Provides group assignment functionality for individual users with like job duties and responsibilities.

From Home Page: Select Administration and from list

Create New Access Group

General Tab

  • Select
  • Assign Group Name
  • Populate Check Boxes based on View/Edit capabilities required by module

Search Results Tab

Populates search results with same fields for all members of access group

Note: This can also be managed at the user level.

    • Select Search Type from Dropdown
    • Highlight required Available Field desired
    • Select to move to Assigned Fields
    • To remove from Assigned Fields, select and move from Assigned Fields

Copy Existing Access Group

- Available to copy an existing group

  • Select Copy Group
  • Change name to desired group name at “This Group Already Exists. Please Specify New Group Name” prompt
  • Select OK

Auditing Tab – Capability to view audit trails based on selections below. Must be assigned in all locations user has access to.

  • Select desired audit tracking or check Select All box
  • Change location if multiple locations are assigned and repeat process
  • Once all tabs have been populated
