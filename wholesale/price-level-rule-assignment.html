Price Level Rule Assignment

Price rules can be set at any level of the inventory tree down to Sku level. When a branch is selected the rule, set pertains to that branch and all branches and Skus below. can also be selected as displayed below with the understanding that ALL items (including non-inventoried items, parts, wheels, etc.) will have rule applied.

Home Screen: Select Inventory from module toolbar, then, then Pricing tab

Select Price Level rules will be applied from dropdown

Add Rule(s)

  • Highlight branch you wish to set rule or go to bottom of inventory tree and search for a specific Sku to apply rule. Once you have made your selection for rule, select
  • Will display line item in blue with the “from” of the branch you selected

Note: Will not display anything above selection.

  • Click in the name field and enter rule name. Be specific (i.e. Firestone LT) or Sku number if setting rule at the Sku level.
  • Tab to Class and select from drop down depending on rule type required
    • Cumulative – Chained rule
    • Additive – Works identically to cumulative rule
    • Fixed – Sets fixed price overriding price level rules
    • Margin Ceiling/Margin Floor
    • Round Nearest – Rounds to the nearest value assigned
    • Round Up – Rounds up to the nearest value assigned
    • Base Change Rule – Changes base factor to something other than default setting
    • Matrix – Pricing set based on range of price or range of units
  • Tab to Operand and select from drop down depending on rule result required
    • %, G% or $ - (GP% selection formula = Base/(1.00-GP%)
  • Tab to Value and select to activate rule prior to populating value
    • Enter rule value
  • Tab to Start Date and select appropriate date from calendar
  • Tab to Expiration Date and select appropriate date from calendar
  • Populate Minimum Cost if Matrix was chosen at class
  • Populate Maximum Cost if Matrix was chosen at class
  • Select to save rule

Note: Total column is created automatially based on rule calcuation settings.
