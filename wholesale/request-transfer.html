Request Transfer

Used to request transfer from another location.

Select from application toolbar. Select from dropdown

  • Select Transfer From location from dropdown
  • Enter Delivery Date (expected date product will be received)
  • Enter Comments if desired
  • Populate Remote Transfer ID (if pertains to company procedure)
  • Populate Sales Order (if pertains to company procedure)
  • Select Add Items
  • Search products desired and add to shopping cart
    • Quantity available is the quantity available at the requested (sending) location
  • Select add to order
    • Will populate and return to transfer request
  • Average Cost of sending location will default into transfer request (do not modify)
  • Select to process transfer (requested status)
    • Will automatically save and assign the next sequential transfer request number
  • Will display dialog box to verify sending request
  • Will display second dialog box informing request was sent successfully
    • References transfer order number on requested from (sending location) side
  • Print for records or at sending location if desired
