Comment Setup

Designed to create commonly used comments, group comments and assign groups by location for consistency and efficiency.

At Home Page: Select from the application task bar then select Comments

Adding Comments

List of all comments needed in Wholesale application

  • Select
    • Comment Code will automatically be highlighted with next sequential number code number
  • Populate Comment Code/short name
  • Populate comment as you would like it to read in comment field of sales order/invoice
  • Checkmark active box
  • Select

Adding Comment Groupings

Groups comments by type or desired use of comment

  • Select
  • Populate Comment Group Code/group name
  • Populate Comment Group Description to describe code group or user group
  • Select
  • Choose desired comments to be available in Comment Grouping
  • Repeat until all desired comments have been chosen
  • Select (Must have at least one comment assigned to group to save)
  • Comments can be deleted from groupings by highlighting line to delete and selecting

Assigning Location Comments

Allows the ability to limit, by location, the comments that will not be utilized.

  • Highlight location desired to assign Comment Groupings
  • Select appropriate grouping from dropdown list (ONLY one per location)
  • Select
