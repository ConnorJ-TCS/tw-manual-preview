Create New Invoice

Designed for the purpose of billing/crediting non-inventoried items and returned goods.

Home Screen: Sales Module and select New Invoice

  1. Enter customer ID or search by customer name
  2. Select Add Items or F2
  3. Enter Sku in Global Lookup
  4. Enter qty and enter; This moves item and qty down to shopping cart
  5. Enter Item(s) until all items have been added
    1. Review and edit quantity, price and cost for accuracy

Note: In this type of transaction, often cost will need to be overwritten to $0, verify costs are correct.

  1. Select add to order – This moves Sku selections to invoice
  2. Add Invoice Comments as reference if necessary
    1. Can also use line item comments if comment will change per line item.
      1. Right click anywhere in the row and select item comment and type comment
      2. Verify check box is checked if print on invoice is desired
  3. Select Save or Print
    1. If print is selected, it will automatically save when it brings up the invoice to print

Note: Processing is only necessary when creating new invoice if you want to immediately push to financial software.
