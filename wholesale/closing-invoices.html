Closing Invoices

Moves Point of Sale sales information to financial software

From Warehousing Module: Select

Closing Tab

  • Delivery date will default to last invoiced date
  • Verify invoice status is OPEN (default)
  • Displays all invoices to close
  • Select

  • Select all or specific routes to close
  • Verify invoice date
  • Select
  • Process bar will move through and process complete will display in progress box

Suggestion*:* At end of each month go through each day and make sure these have all processed.
