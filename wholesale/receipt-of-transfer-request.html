Receipt of Transfer Request

Used to receive requested transfer.

Within Find section of home page, Select

  • If WMS is used, select and receive in WMS prior to receiving product
    • Transfer Request will be (In Transit) status when sending location has fulfilled transfer request
    • Send to WMS and Receive function will only be available in this status
  • Once received in WMS or no WMS is present, verify quantities on transfer request and make any necessary changes to Qty. Received
  • Select
  • Dialog box will display verify receipt of all quantities on grid
    • Reminder to check quantities
  • Transfer Receipt will display for printing if desired
    • Transfer Request will be marked Complete or Partially Received depending on quantities received.
