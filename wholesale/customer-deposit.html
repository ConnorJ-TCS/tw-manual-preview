Customer Deposit

Home Screen: Select then select New Customer Deposit from Start a Task

Create Customer Deposit

  • Select Customer Search Icon
  • Enter known information in search window (Customer Number, Name, Phone)
  • Select Search
  • Highlight and select OK to desired customer
  • Select Order ID Search Icon if order has already been created
    • Description field required
  • Select desired order if one present on search results screen and select OK
  • Select desired Payment Type
    • If check, enter name and check number (required)
    • If credit card, select card type
  • Enter Payment Amount
  • Select Reset if payment information was needs modified
  • Select Add Payment
    • Displays to the right under added payments
  • Select Save Deposit
    • Populates Deposit ID
  • Select Cancel Deposit if necessary
  • Select Print for receipt to customer
    • Error message will display to verify population of Description field

Reverse Customer Deposit

  • Find and open Customer Deposit
    • FIND: Customer Deposits
  • Select Reverse
    • Confirm you want to reverse, select YES
