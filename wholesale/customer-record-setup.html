Customer Record Setup

Accounts Receivable customer setup is one of the top three areas that consistency, completeness, and accuracy will greatly impact workflow.

General Tab

Defines all general customer information. Populate as needed bases on your business practices and procedures.

  • Customer Name: Legal name
  • Customer ID: Auto population unless choose to override
  • Short Name: Abbreviated searchable name
  • Customer Class: Select from predetermined drop-down list
  • Status: Active by default
  • Salesperson Name: Person responsible for account
  • Customer Since: Calculated field not editable
  • Balance: Calculated field imported from financial software
  • Terms: Select term approved by credit manager
  • P.O. Required: Check only if all orders are required to have a PO
  • Tax Group: Select appropriate tax from dropdown
    • Taxable by default unless Exempt is chosen from dropdown
    • Select Nome if default tax rate should be that of the servicing location
  • Department Code: Select appropriate department code. If not used select 00
  • Tire Tax Exempt: Check box if tire tax exempt
  • Tax Exemption Number: Populate if exemption box is checked.
  • Ship Method: Select default ship method for customer from dropdown
  • Ship Complete: Check only if the customer prefers to have entire order ship at one time
  • Credit Limit: Enter amount approved by credit manager
  • eCommerce Credit Factor: If applicable
  • Unused Credit: Calculated field imported from financial software
  • Default Price Level: Select appropriate price level from dropdown box
  • Discount %: Enter percentage if applicable
  • Finance Charge: Enter percentage if applicable
  • Memo 1: Free form field – WILL print on invoice
  • Memo 2: Free form field – WILL NOT Print on invoice (600 varchar field)
  • Messages: Free form field – WILL NOT print on invoice
    • Show Alert: If checked will display at creation of sales order

Addresses Tab

Defines all address, pricing, shipping and internet ordering information by address. Address information CAN be different than general customer information. Populate as needed bases on your business practices and procedures.

  • Address ID: Primary will auto populate in Address ID
    • If shipping address and billing address are not the same, consider using PRIMARY and SHIPPING in route ID so they can be properly selected above.
    • If additional shipping addresses, consider a naming convention to keep consistent.
    • If multiple shipping addresses, consider using street name for additional
    • If shipping to a separate customer, consider using customer name
    • If national account, consider using customer main account number for reporting
  • Status: Active by default
  • Address 1: UPS approved address
    • Address verification can be obtained on www.usps.com
    • Suggest ALL CAPS and no punctuation
  • Address 2: Other address information
    • Used for PO Box or other address related data
  • Country: Select from drop down box
  • Zip Code: Enter zip code – city/state will auto populate
    • Verify city matches postal service approved city
  • Phone Number: Include extension if available
  • Fax Number: If applicable
  • Email Address: Full email address if applicable
  • Website: Customer website if applicable
  • Home Location: Designation of primary distribution center based on address
  • Tax Group 1 and 2: Make sure they are both populated
  • Price level: Default price level for location (Can be different than general information tab)
  • Ignore Customer Pricing: Check if applicable
  • Consolidate Orders on Invoice: Check if applicable
  • FET Exempt: Check if applicable
  • Delivery fee exempt: Check if applicable
  • Tire Fee Exempt: Check if applicable
  • Routes Box 1: Select ship method for address (Can be different than general information tab)
    • If Primary is BILLING address only – select BILLING as ship method
    • If Primary is the billing and shipping address – select designation on customer setup form
  • Routes Box 2: If ship via is route in box above, select route again**.**
    • Assign route unless route manager will handle route assignment
  • Return to top of Address tab and complete, once all addresses have been added
    • Primary Primary
    • Billing Primary
    • Shipping Address Routinely used shipping address if more than one

address exists (defaults in sales order)

eCommerce Tab

Settings for Internet Ordering based on address.

  • Electronic Ordering
    • Must be checked “Enabled” if choosing to order via website
  • Append Orders
    • Must be checked if choose to combine orders placed on website
  • Compare PO Number
    • Creates new order if PO number doesn’t match previous orders placed
    • MUST be checked if append orders is checked unless otherwise stated

Backorder Fill Priority Tab

Can be used to set customer priority for back order filling. Also, can be done in “Fill Backorder” module.

Custom Fields Tab (User Defined):

Can be used to add additional information pertaining to a customer (i.e. program account numbers, tax exempt numbers, etc.) based on address ID.

  • Provide administrator with desired field name(s) and field number(s) create**.**
    • (See character requirements below)
      • Fields 1-5 bit (check box)
      • Fields 6-10 varchar (50)
      • Fields 11-15 varchar (200)
      • Fields 16-20 integer
      • Fields 21-30 numeric (12,2)
      • Fields 31-35 datetime
  • When complete with all customer setup information, Save and Close
