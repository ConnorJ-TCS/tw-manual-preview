Automatic Transfer

Used to create a transfer in sending location and automatically updates both sending and receiving inventory.

Select from application toolbar. Select from dropdown

  • Enter transfer customer (header information will populate)
  • Delivery method will default to Pickup/Will-Call
  • Enter Comments if desired
  • Select Add Items or add via Quick Add
  • Search products desired and add to shopping cart
    • Quantity available is the quantity available at the requested (sending) location
  • Select add to order
    • Will populate Automatic Transfer
  • Average Cost of sending location will default into transfer (do not modify)
  • Continue adding items until all desired product has been added
  • Select Process
    • Automatically generates and processes transfer request for receiving location and processes sending location transfer order (automatically removing/adding product from/to inventory quantity on hand)
  • Invoice from sending location will display for printing
