All notes from the start of version 25 through this patch. The patch number beside each note is the first patch that shipped it.

Retail

New System Settings

ASL Fetch Page Size 25.5.6TWHD-3722

Number of ASL locations considered for fetching ASL values of SKUs in a batch

Inventory Receipt - Populate Quantity Received 25.4.3.1TWHD-3560

Controls whether the "Quantity Received" field on inventory receipts is populated with outstanding quantities from the PO or set to 0 by default

PDF Printing - Use Legacy PDF Rendering Method 25.5.4TWHD-3685

Indicates whether to use the legacy method for PDF rendering using Adobe Reader. (Required on some Windows 10 and earlier versions)

Reorder Point Calculation Method 25.5.7TWHD-3672

Determines whether the reorder point calculation uses only Quantity on Hand (QoH) or Quantity on Hand minus Committed (QoH - Committed)

Transfer Pricing Source 25.5.6TWHD-3986

Determines whether transfer prices are derived from the sending location or the receiving location

Update Cost Upon QuickQuote Conversion 25.4.1.1TWHD-2638

Determines if and when the cost of items on a Quick Quote are updated upon conversion to a Service Request. “Zero Cost” will update any $0.00 with that item’s “Invoice” Default Cost. “Always” will update the cost of every item with their “Invoice” Default Cost, so long as it’s greater than $0.00. “Never” will leave all costs of items on a Quick Quote unchanged

New Access Rights

Controls the user's ability to view the Quantity on Hand column within the 'Inventory Items' grid of the 'Manage Inventory Snapshot' window

Appointments - Configure Calendars 25.4.1.1TWHD-3302

Credit Card Terminal "Do Not Ask Again" Selection 25.4.3.2TWHD-3644

Inventory Receipt - Allow Duplicate Reference Numbers 25.5.6TWHD-3940

Item - Edit Average Cost 25.4.1.1TWHD-2779

Ability to edit the Average Cost from the Site Detail Tab on the Item Details and Manage Inventory windows

Item - Edit Last Cost 25.4.1.1TWHD-2779

Ability to edit the Last Cost from the Site Detail Tab on the Item Details and Manage Inventory windows

Service Request - Complete Order 25.5.5TWHD-3826

Controls whether a user can see and use the “Complete Order” button in a service request

Service Request - Expired Discount 25.4.1.1TWHD-1166

Ability to retain expired discounts and coupons which were previously applied to a service request

Service Request - Item Description 25.5.1TWHD-3732

Controls whether a user can modify the item description on a service request

Service Request - Revise Order 25.5.5TWHD-3827

Controls whether a user can see and use the “Revise Order” button in a service request

Service Request – Tire Quote 25.5.6TWHD-3843

Controls the user’s ability to access and use the F1 Tire Quote screen within the Service Request and related workflows

Special Program: Service Request - Prod. Code 25.4.3.3TWHD-3608

Controls whether a user can edit the Prod. Code value in the service request or item detail window when a special program is assigned
