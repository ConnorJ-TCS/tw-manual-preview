New in version 25.5.9

New in 25.5.9Everything through 25.5.9

Retail: 12 cases. Wholesale: 1 cases.

Retail

New Features

Tire and Parts Search

  • Purchase order availability checks for IAP/ISE suppliers now resolve the correct line code for each individual item while continuing to prioritize the most recently modified entry TWHD-4209

Bug Fixes

Service Requests and Invoicing

  • Users with the “Service Request - Order Comment”, “Service Request - Order Private Comments”, or “Service Request - Order Public Comments” access rights set to EDIT can now add or modify comments on closed and invoiced work orders TWHD-4354
  • The “Service Request - Change Invoice Date” access right is now correctly enforced, ensuring only users with EDIT permissions can modify invoice dates on open Retail Service Requests. Closed orders are now strictly read-only and do not allow invoice date changes regardless of user permissions TWHD-4360
  • Customizations to the lube sticker stored procedure, cusp_SrHeader_GetDataForLubeSticker, are now preserved during system upgrades TWHD-4339

Tire and Parts Search

  • ISE stores can now add catalog parts to a Service Request from the F2 Parts search without an error TWHD-4383
  • Improved the reliability of ASL quantity and detail data loading in F1 Tire Search when searching by tire size only TWHD-4322
  • Resolved an error in F1 Tire Search that prevented users from viewing ASL details TWHD-4384
  • Tire Search now correctly displays available ASL and vendor data even if a specific vendor lookup fails or is misconfigured TWHD-4344
  • Fixed an issue in the Tire & Wheel Lookup window where selecting a tire fitment could incorrectly filter out valid inventory from search results TWHD-4357

Customers and Vehicles

  • Corrected an issue where oil specifications were not deferred until the Vehicle Specs or Oil Settings sections were accessed while ISE Motor Specs were enabled TWHD-4305

Payments and Cash Drawer

  • Fixed an issue where cash payments with change could incorrectly show a remaining balance in QuickBooks Online after “429” error retries TWHD-3721

Wholesale

Bug Fixes

Process Orders, Shipping, and Routes

  • Corrected the Process Orders validation to ensure orders with backordered items are correctly identified and blocked from processing TWHD-4411
