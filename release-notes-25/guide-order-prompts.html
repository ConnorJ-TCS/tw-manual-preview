Retail – Order Prompts

A comprehensive set of features aimed at enabling new prompting functionality for customer data capture.

New System Settings

Order Prompts - Show Previous Prompts by Default

When enabled, the ‘Show Previous Prompts’ checkbox in the Order Prompt window will be checked by default. If disabled or not set, the checkbox will be unchecked when the Order Prompt window is opened.

New Access Rights

Manage - Order Prompts

Allow access to Order Prompts under the Location Setup menu.

Introduction of Order Prompts

Order Prompts provide a way to capture and manage additional data related to an order. Prompts can be configured to appear at different order states and user actions, depending on requirements. The questions presented are fully customizable, and answer formats include Alphanumeric (free text), True/False, single-select lists, or multi-select lists.

Prompts may be triggered during various actions within an order state, such as during the Save action, when assigning a Customer, or when assigning a Vehicle to the order.

Each prompt can be designated as “Required” by selecting the respective order state in the “Required” drop-down. If a status is selected as Required, all subsequent statuses also treat the prompt as required. In these cases, the corresponding question must be answered before the order can be saved.

Order Validation and Prompts UI Update

The Order Validation window has been modified to become the Order Validation and Prompts window, allowing for display of any pending Order Prompts, including those required for the current order state. The updated interface maintains the presentation of pending order validations and now includes pending order prompts at the bottom of the UI.

If no pending order prompts exist, it is still possible to view previous prompts by selecting the new “Show Prompts” button. Additional previous prompts not initially visible can be accessed using the “Show Previous Prompts” checkbox within this interface.
