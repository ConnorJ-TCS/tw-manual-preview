Retail – Enhancement of Purchase Order and Service Request Interaction

A comprehensive set of improvements to allow new workflows, as well as streamline existing workflows.

New Access Rights

Purchase Orders - Close PO

Allow access to Close PO functionality for Purchase Orders not linked to a Service Request. For Purchase Orders linked to a Service Request see other relevant access rights.

Service Request - Cancel PO/PO Items Linked to SR

Controls whether users can cancel a PO or PO items linked to a Service Request when removing or declining the linked item.

Service Request - Close PO/PO Items Linked to SR

Controls whether users can close a PO or PO items linked to a Service Request when removing or declining the linked item.

Service Request - Complete PO/PO Items Linked to SR

Controls whether users can complete a PO or PO items linked to a Service Request when removing or declining the linked item.

Service Request - Disassociate PO/PO Items Linked to SR

Prevent/allow user to disassociate PO/PO Items linked to a Service Request, within the Service Request window.

Sourcing Manager – Cancel PO/PO Items Linked to SR (RENAME)

Controls whether users can cancel a PO or PO items from within the Sourcing Manager - Outside Purchase window.

This Access Right previously existed under the name “Purchase Order – Cancel PO/PO Items Linked to SR”.

Sourcing Manager - Close PO/PO Items Linked to SR

Controls whether users can close a PO or PO items from within the Receive Open Purchase Order window, within Sourcing workflows. Requires ‘Purchase Orders - Close PO’ permission as well.

Sourcing Manager - Receive PO/PO Items Linked to SR (RENAME)

Controls whether users can receive a PO or PO items from within the Sourcing Manager - Outside Purchase window.

This Access Right previously existed under the name “Purchase Order – Receive PO/PO Items Linked to SR”.

“Close” Functionality

TireWorks HD now allows users to efficiently update Purchase Orders in a Partially Received status so that if outstanding quantities are no longer anticipated, the order can be marked as “Fully Received.” Previously, this required users to manually open the Purchase Order and adjust the quantity to match items already received.

Currently, both standalone Purchase Orders and those linked to Service Requests can be “Closed” via a single button, which automatically recalculates PO quantities and updates the status. This functionality is accessible from within the Purchase Order interface or directly through a Service Request, enabling users to manage associated Purchase Orders without navigating away from their current workflow.

Access rights are available to define user permissions for closing Standalone and Service Request-linked Purchase Orders.

Please note, this feature is applicable exclusively to Partially Received purchase orders.

“Disassociate” Functionality

TireWorks HD now allows users to disassociate Purchase Orders from Service Request line items. Previously, users were required to cancel the Purchase Order if the Service Request line item was declined or deleted. This update enables the Purchase Order to remain open and receivable, regardless of the status of the Service Request.

“Complete” Functionality

TireWorks HD now allows users to efficiently receive any outstanding quantities associated with an open Purchase Order. By selecting this option, the system will automatically generate and process an Inventory Receipt for all remaining items.

UI/UX Enhancements

To facilitate the integration of new workflows, several improvements have been made to the user interface.

User Prompts for Declined or Deleted Items

When an item on a Service Request with an open Purchase Order is declined or deleted, the application now prompts the user to select the appropriate action regarding the Purchase Order. Based on the user's access rights and the status of the Purchase Order, options will be presented for Closing, Canceling, Completing, or Disassociating. If the user does not have permission to perform any of these actions, they will be restricted from declining or deleting the item, ensuring that only authorized users can modify service request items associated with pending purchase orders.

"Close" Button for Standalone Purchase Orders

A dedicated "Close" button has been added to the Purchase Order interface, the Find > Purchase Order UI, and the Purchases tab of the home screen to streamline access to this function. For any Purchase Order eligible for closure—specifically those that are partially received—the button will be visible, allowing users to initiate the closure action directly without needing to access the original Purchase Order.
