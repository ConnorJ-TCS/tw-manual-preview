Retail – iPOSPays Payment Processing

A comprehensive set of features aimed at enabling the integration between TireWorks HD Retail and iPOSPays.

New System Settings

iPOSPays Cash Payment Discount Code

Set the discount code to be applied to the service request when the customer chooses “Cash Payment” on the credit card terminal. This setting is only effective if iPOSPays Cash Discounting - Active is enabled.

iPOSPays Cash Discounting - Active

This enables the Cash Discounting feature within TWHD only. Additional configuration is required within the iPOSPays web portal! Ensure to configure the iPOSPays Cash Discount Code system setting appropriately.

Location Selection - Do Not Ask Again For Terminal

Stores the user’s choice of not asking for last selected credit card terminal again when logging in to a location.

Location Selection - Selected Credit Card Terminal

Stores the user’s last selected credit card terminal for reuse when logging in to a location.

IPosPays Base Url

Base Url for iPOSPays endpoints.

Location Selection - Selected Credit Card Terminal

Stores the user’s last selected credit card terminal for reuse when logging in to a location.

New Access Rights

Location Management - Credit Card Terminals

Allow access to Credit Card Terminals under the Location Setup menu.

Full Payment Processing Integration

TireWorks HD now supports integration with iPOSPays for credit card payment processing. This functionality is available wherever credit card transactions are permitted within the application, including Customer Deposits, Receipts on Account, and Service Requests. Additionally, users can void payments or process direct refunds through this integration.

Credit Card Terminal Management

The integration utilizes standalone, Android-based Credit Card terminals that communicate securely via the iPOSPays API. As a result, TireWorks HD sessions do not require a computer to be directly connected to a terminal. Terminals may operate independently of any workstation.

For efficient terminal management, users at locations enabled for iPOSPays will be prompted to select a terminal upon logging in to TireWorks HD. The selected terminal can be saved by choosing “Do Not Ask Again…”, eliminating future login prompts for that location.

Users may change the active terminal at any time by navigating to TireWorks > My Preferences > Credit Card Terminal tab. Here, they may also reset the “Do Not Ask Again…” option if necessary and test the status of the chosen terminal to ensure it is operational.
