New in version 25.4.2.1

New in 25.4.2.1Everything through 25.4.2.1

Retail: 7 cases. Wholesale: no targeted changes.

Retail

New Features

Customers and Vehicles

  • A Cinch GET endpoint has been integrated to allow users to securely retrieve and download messages for a specific customer, with results provided in an easy-to-use JSON format. This enhancement improves access to customer communications and supports better customer service TWHD-3455

Transfers and Sourcing

  • The Sourcing Manager now allows users to request transfers for multiple items at once, streamlining the process and enabling selection of available items from a single ASL location in one request. All items are checked by default in the transfer screen, and only fully available items are included in the transfer, with clear messaging for any excluded items. The existing workflow remains unchanged for single-item transfers TWHD-1337

Other Integrations

  • The Communication Portal now displays Cinch message threads with improved filtering, message status, and direct reply capabilities, allowing users to manage all customer communications in one place. Tags for internal and external messages have been added for clarity, and all existing functionality remains unchanged TWHD-3397

Beta Issues

  • Variance amounts are now correctly calculated and displayed in the Program Reconciliation Transaction window when Vendor Credits are generated manually TWHD-3477
  • Fixed an issue where clicking the “Item Detail” icon on the Service Request screen caused an Object Reference Error; the Item Detail window now opens without any error messages TWHD-3504
