New Features

Sales Orders and Invoicing

  • The “Freight” field is now available for editing within Purchase Orders, Inventory Receipts, and AP Invoices. Users with the relevant access permissions may modify this field according to document type. Please note that the entered freight amount will not impact order total calculations nor will it be reflected in any accounting integrations 25.4.1.1TWHD-1517TWHD-1516TWHD-1515

Inventory and Items

  • Inventory Accounts now supports company-level configuration and location-level inheritance 25.5.10TWHD-3423
  • The Allocations tab was added to Wholesale Inventory Management 25.5.10TWHD-2941
  • The Stocking tab was added to Inventory Management 25.5.10TWHD-4053
  • The Movement tab was added to Inventory Management for item history 25.5.10TWHD-4054
  • The Net Specials tab was added to Item Detail 25.5.10TWHD-4056

Accounting and Integrations

  • The QuickBooks Desktop integration no longer depends on the locationacct table for determining the unentered liabilities account; if not specified in the config file, the system now correctly uses the inventoryacct table instead 25.4.3.3TWHD-3625

Setup, Reports, and Access Rights

  • The application now supports SSRS Authentication via a Security Profile with “Use Manual Credentials”, or via Application Config settings with “Use App Config Credentials” 25.4.1.1TWHD-1287

Performance and Stability

  • Wholesale invoice processing database logic was improved to prevent deadlocks during concurrent invoice line updates 25.5.10TWHD-4423
  • Wholesale sales order and line-item updates were hardened to prevent deadlocks and save failures during concurrent user activity 25.5.10TWHD-4424
  • The use of “ntext” SQL Datatype has been eliminated 25.4.1.1TWHD-3169

Bug Fixes

Sales Orders and Invoicing

  • Sales Orders now save after a retread is added, and later saves keep working 25.5.10TWHD-4948
  • Invoices generated at the same time for the same warehouse no longer receive the same invoice number and fail to save 25.5.10TWHD-4749
  • Print Delivery Invoices in Shipment Manager no longer creates invoices with a header and no line items 25.5.10TWHD-4466
  • Process Orders now detects insufficient inventory for ecommerce orders with Skip Qty Check enabled and routes them to backorders instead of Shipment Manager 25.5.7TWHD-4205
  • Wholesale invoices with split payment terms now integrate successfully when document IDs contain hyphens 25.5.7TWHD-4201
  • New Invoice discounts now calculate immediately when entered, with validation for invalid discount entries 25.5.7TWHD-2749
  • Sales order completion and modification timestamps now use each location’s local time instead of server time 25.5.7TWHD-2434
  • Return invoices now correctly populate the SO_ORDER_ID in the Ws_Invoice table, ensuring header and detail lines are linked for accurate reporting and integrations 25.5.6TWHD-3424
  • Fixed an issue where invoices with percentage-based discounts in Wholesale were not matching totals between TireWorks and QuickBooks 25.5.6TWHD-1788
  • Fixed an issue where wholesale to retail transfers failed to invoice due to application timeouts and database locks, ensuring transfers now complete successfully and are properly linked between wholesale and retail systems 25.5.4TWHD-3862
  • Users can now open and interact with the AP Invoice window in Purchasing without encountering object reference errors 25.4.3.2TWHD-3567
  • Addressed a problem in Shipment Manager that did not rollback changes when the invoicing process was unsuccessful 25.4.1.1TWHD-2615

Process Orders, Shipping, and Routes

  • Corrected the Process Orders validation to ensure orders with backordered items are correctly identified and blocked from processing 25.5.9TWHD-4411
  • The Route Management window now correctly reorders only the selected Route Stop when using the Up and Down arrow buttons 25.5.5TWHD-3047
  • Resolved an issue in Shipment Manager where orders were displayed by Requested Date instead of Estimated Date 25.4.1.1TWHD-3029
  • Updated the Process Orders window to allow the “EstRouteDate” field to be correctly refreshed 25.4.1.1TWHD-2893

Purchasing and Receiving

  • Processing an Inventory Receipt from Receive PO no longer fails with a “Value cannot be null” error when “Use current costs for PO items” is off 25.5.10TWHD-4455
  • Canceled Inventory Receipts no longer appear in the Add Items list when creating AP Invoices 25.5.7TWHD-3231
  • Inventory Receipt item costs now update in real time when Use Current Costs for PO Items is changed 25.5.7TWHD-2557
  • Fixed an issue where the "Submit PO" button on the Purchase Orders screen failed to send electronic purchase orders to third-party vendors, resulting in a null reference error 25.5.4TWHD-3614
  • Fixed a bug that allowed users to reduce Purchase Order quantity below the quantity already received 25.4.1.1TWHD-2836

Transfers

  • Transfer order processing now creates only one transfer request per order and rolls back related records on failure 25.5.6TWHD-3928

Inventory and Items

  • On Inventory Management and Item Detail Site Detail, Remove from Bin, Move Up, and Move Down are now disabled when there are no preferred bins or none is selected, so they no longer show a system error 25.5.10TWHD-4625
  • The Invoice OP Sku details UI now matches the Sales Order workflow by displaying SKUs from both the OP Sku submanufacturer and the IC_Sku_Usercost table, and the grid includes vendor ID and reference number columns for consistency 25.5.6TWHD-3903
  • The prompt for vendor and reference number details for outside purchase SKUs now only appears when processing new invoices that will trigger Inventory Receipt and AP Invoice generation 25.5.6TWHD-3902
  • Fixed an error that prevented users from saving new SKUs in Inventory Management 25.5.4TWHD-3847
  • Fixed filtering logic for the 'Use Inventory Tree Lookups' feature 25.4.1.1TWHD-2532

Customers and Pricing

  • Wholesale customer address deletion now persists without the quoted identifier error 25.5.10TWHD-4472
  • Updated Customer Pricing Report calculations to account for active Special Price Levels 25.4.1.1TWHD-2673

Accounting and Integrations

  • Adjusted item cost calculation during AutoReplenishment transfers from Retail 25.4.1.1TWHD-2734

Setup, Reports, and Access Rights

  • Add New State in Location Management Tire Tax setup now works without an error 25.5.10TWHD-4577
  • Configure Search Results now keeps Field Name and Header Text sorting aligned for invoice results 25.5.7TWHD-2916
  • Removed redundant “SMTP” tag from the application configuration file 25.4.1.1TWHD-2710
  • Fixed error encountered during new Security Group creation 25.4.1.1TWHD-2940

Performance and Stability

  • The special program upgrade script was corrected to remove references to retail tables and resolve foreign key constraint errors, ensuring the upgrade completes successfully without data integrity issues for wholesale customers 25.5.5TWHD-3878
  • Corrected Quantity on Hand logging errors when the same item appears multiple times on an order 25.4.1.1TWHD-2607
