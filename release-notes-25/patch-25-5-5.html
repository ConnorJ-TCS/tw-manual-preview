New in version 25.5.5

New in 25.5.5Everything through 25.5.5

Retail: 18 cases. Wholesale: 3 cases.

Retail

New Access Rights

Service Request - Complete Order TWHD-3826

Controls whether a user can see and use the “Complete Order” button in a service request

Service Request - Revise Order TWHD-3827

Controls whether a user can see and use the “Revise Order” button in a service request

New Features

Service Requests and Invoicing

  • The "EDIT" option has been removed from the "Service Request - Show Tire Details Screen" access right TWHD-3842

Customers and Vehicles

  • The Find > Customer search screen now remembers each user's last-used state of the partial search checkbox next to the Customer ID field, so your preferred search behavior is retained across sessions TWHD-3412

Setup, Users, and Access Rights

  • The "VIEW" option has been removed from the "Search Results Configuration - User Selection" access right TWHD-3845

Bug Fixes

Service Requests and Invoicing

  • Tire tax exemption status now correctly persists from Customer to Quick Quote to Service Request, ensuring tire tax is not applied for Tire Tax Exempt customers and the exemption flag is accurately reflected throughout the process TWHD-3720

Tire and Parts Search

  • The access right previously labeled “Inventory Costs – ASL” has been renamed to “Inventory Price – ASL,” and its description now accurately states it controls visibility of the “Price” column in the ASL view. No functional behavior was changed TWHD-3846

Pricing, Packages, and Discounts

  • The stored procedure cusp_Sku_GetByCompanyIdLocationIdSkuIdListForPricing has had parameter names corrected TWHD-3683

Transfers and Sourcing

  • Rapid or repeated clicks of the "Done" button during PO receipt in the Sourcing Manager no longer cause partial receipts, inventory discrepancies, or application lag; all items are now received in a single transaction and the "Qty Received" column updates accurately TWHD-3806

Performance and Stability

  • Some stored procedures have been updated to include 'SET QUOTED_IDENTIFIER ON' at the beginning, preventing errors at runtime TWHD-3698

Wholesale

Bug Fixes

Process Orders, Shipping, and Routes

  • The Route Management window now correctly reorders only the selected Route Stop when using the Up and Down arrow buttons TWHD-3047

Performance and Stability

  • The special program upgrade script was corrected to remove references to retail tables and resolve foreign key constraint errors, ensuring the upgrade completes successfully without data integrity issues for wholesale customers TWHD-3878

Web Services

New Features

AMI/Mopar

  • Estimated delivery dates sent to AMI are now correctly converted to UTC using the “SQL Database Time Zone” system setting, ensuring accurate ETAs for customers and consistency across all deployment types TWHD-3471

Bug Fixes

eXceedService

  • The GetOrderStatuses API now correctly includes CustomerMemberId and CustomerVehicleId in its response when these values exist in the database, improving data accuracy for integrations and user workflows TWHD-3891

TCS Inspect Service

  • Users can now convert appointments using the TCS Inspect app regardless of whether the appointment is locked in the UI, resolving previous errors and ensuring smooth appointment conversion TWHD-3892

TDWebservices

  • Tire line items with decimal quantities are now correctly added to Purchase Orders via eXceedPOInterface, using the floor integer value for tire items (SkuType = 0), while non-tire items remain unaffected TWHD-3652
