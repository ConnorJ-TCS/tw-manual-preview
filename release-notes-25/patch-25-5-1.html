New in version 25.5.1

New in 25.5.1Everything through 25.5.1

Retail: 7 cases. Wholesale: no targeted changes.

Retail

New Access Rights

Adv. Inv. Count - Inventory Snapshot – QOH TWHD-3248

Controls the user's ability to view the Quantity on Hand column within the 'Inventory Items' grid of the 'Manage Inventory Snapshot' window

Service Request - Item Description TWHD-3732

Controls whether a user can modify the item description on a service request

Bug Fixes

Service Requests and Invoicing

  • GL account creation for Special Programs now correctly uses the BILL TO customer's department code instead of the SOLD TO customer's code, ensuring accurate department assignment in all displays and reports TWHD-3741

Inventory and Items

  • Tire SKU details in Manage Inventory now save and recall Tire Data fields correctly, and users receive a save confirmation message when changes are made. The Tire Size dropdown performance issue will be addressed separately TWHD-3682
