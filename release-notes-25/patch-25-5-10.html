New in version 25.5.10

New in 25.5.10Everything through 25.5.10

Retail: 80 cases. Wholesale: 14 cases.

Retail

New System Settings

Engine Oil Non-Catalog Requires Sourcing TWHD-4253

Determines whether non-catalog Engine Oil items follow standard sourcing and inventory rules instead of bypassing sourcing. Disabled by default

Outlook Graph AddressUrl TWHD-2786

Url of the Microsoft Graph at Azure for sending the email

Outlook Graph ClientId TWHD-2786

Client Id of the application registered at Azure AD for sending the email

New Access Rights

Inventory Management - Company Inventory Accounts TWHD-3394

Controls a user's ability to view and manage company-level inventory account mappings

Inventory Management - Location Inventory Accounts TWHD-3394

Controls a user's ability to view and manage location-level inventory account mappings

Outlook Authentication TWHD-2786

Allow user to be prompted with Outlook Authentication

New Features

Payments and Cash Drawer

  • 1stMile card sales now include the store, Service Request, customer, and customer creation date, so 1stMile has the order details behind each sale TWHD-4220

Purchasing and Receiving

  • QuickBooks Online vendor imports now avoid putting VendorID in Last Name and set imported vendors active TWHD-4202

Transfers and Sourcing

  • A new “Engine Oil Non-Catalog Requires Sourcing” system setting lets stores have non-catalog engine oil on packages follow standard sourcing and inventory rules, preventing negative inventory. The default is off TWHD-4253

Inventory and Items

  • Inventory Accounts now supports company-level and location-level configuration TWHD-3394

Messaging, Email, and Printing

  • Service Request printing enhancements are enabled for all workflows for faster, more consistent performance TWHD-4351
  • Modern authentication was implemented for Outlook email capabilities TWHD-2786

Bug Fixes

Appointments and Quick Quotes

  • Appointment Calendar boxes now lead with the customer name and show the phone number beneath it, show the full order total including tax and fees, and no longer carry the “(*Multi)” tag on ordinary appointments TWHD-4883
  • Multi-package appointments on the same calendar now draw as one block, including when a package with no service duration sits between other packages, instead of as overlapping duplicate blocks TWHD-4758
  • Changing the time on a multi-package appointment now schedules its packages one after another from the new start time, instead of all at the same time TWHD-4581
  • Appointments with no service duration can now be dragged to a new time, and several scheduled at the same start time now display side by side on the Appointment Calendar TWHD-4674TWHD-4562
  • Multi-package appointments created before 25.5.10 now display as one continuous block on the Appointment Calendar TWHD-4582
  • Stretching a multi-package appointment on the Appointment Calendar now keeps its new length, and split packages recombine into one block when dragged back together TWHD-4718
  • Multi-package appointments now stay grouped on one calendar when dragged to a new time slot or calendar TWHD-4459
  • Packages added through Schedulable Services now use the customer’s assigned price level TWHD-4002
  • Multi-package appointments now stagger package start times so calendar openings reflect full duration TWHD-3379
  • Quick Quote vehicle lists now refresh when the selected customer changes TWHD-2944
  • Customer searches in Quick Quote and Appointment now work with a single name and phone number TWHD-1480

Service Requests and Invoicing

  • Setting Sp. Program back to None on a Service Request now restores the order’s Tax Detail, Tire Tax Exempt, and Terms from the customer instead of keeping the program’s values, including when the Goodyear National Account Selector is closed without choosing an account TWHD-5084
  • Service Requests now show a mileage warning and cannot be completed when Mileage Out is 0 and Mileage In has a value. A Mileage Out lower than Mileage In is still caught TWHD-4422
  • The Previously Declined Services list in the Service Advisor now drops a service once it has been invoiced at the same store, added to an order, or marked “Don't Ask Again” TWHD-4769TWHD-4770
  • Failed signature capture during invoicing now rolls back order closure instead of leaving an incomplete closed order TWHD-4491
  • Service Request invoice emails now use the standardized Attachment.pdf filename TWHD-4477
  • Reversal Service Requests now preserve the original order’s removed-vehicle state TWHD-4430
  • Goodyear National Account searches now use the user-selected document type TWHD-2089
  • Goodyear National Account searches now honor the PreferTireHQ configuration TWHD-2090
  • Loyalty Rewards now pre-fills customer information and updates enrollment status immediately TWHD-3063

Tire and Parts Search

  • Tire, Wheel, and General searches in Tire Lookup now return as quickly as they did before 25.5.10 for stores whose database runs SQL Server Standard Edition, with the same items and quantities TWHD-4885
  • Service Request and invoice printouts now show tire inflation, lug nut torque, and other vehicle specifications from ISE when the “EPICOR ISE Service - Motor Spec endpoints enabled” system setting is on TWHD-4177
  • Wheel Search in F1 Tire & Wheel Lookup now opens normally instead of going blank and locking TireWorks HD TWHD-4631
  • Rapid F3 Lookup search actions no longer duplicate ASL quantities TWHD-4171
  • Tire Quote printing no longer fails with an out-of-memory error TWHD-4429
  • F1 Tire & Wheel Lookup Size Search now validates non-numeric input instead of throwing an error TWHD-4433

Customers and Vehicles

  • Customer names entered with an apostrophe are now saved, shown, and sent to QuickBooks Desktop with a single apostrophe instead of two. Names already saved with two apostrophes are left as they are and now show both TWHD-3922
  • Find > Customer name, Customer Id, address, and phone searches now return much faster on large customer lists, with the same results TWHD-4884
  • Quick Quote now disables the Vehicle Detail button and clears the earlier customer's vehicle details when you decline to add the selected vehicle to a newly chosen customer TWHD-4484
  • Sorting now works on the Customer Merge screen for the Contact Details column on the Members and Addresses tabs and for the Plate and State columns on the Vehicle tab TWHD-4471
  • Carfax QuickVIN lookups now fill in the VIN for electric vehicles TWHD-4249
  • Customer Merge no longer errors when sorting contact or address data before moving records TWHD-2895
  • Customer Merge no longer fails when the source customer has CallNotes TWHD-2982
  • Customer Deposit Report emails no longer fail because of a missing system entry TWHD-3413
  • Customer Merge no longer throws a CollectionView error when selecting customer records TWHD-3896
  • Customer Merge Copy Order now consolidates order history without duplicating vehicles TWHD-3926
  • Large fleet and enterprise customer searches, selection, and saves now perform better TWHD-4230
  • Vehicle service data no longer appears on or overwrites other customers’ service requests TWHD-4248
  • Customer vehicle merges no longer fail with a database error TWHD-4265
  • Irrelevant tabs were removed from the Archived Service History report window TWHD-4278
  • Customer Members now has a scroll bar when the member list exceeds the visible area TWHD-4449

Payments and Cash Drawer

  • Manual credit card entry now works when Merchant Partners or 1stMile readers are not connected TWHD-4478
  • Cash Drawer Total Cash/Check now updates when the date changes TWHD-4382

Pricing, Packages, and Discounts

  • Package lines with no package price now come in at the order’s Price Level, whichever user adds the package and whether it is added from Service Package, Quick Add, related packages, Carfax, or FSM, on Service Requests, Quick Quotes, and Appointments. They also reprice when the order’s Price Level changes TWHD-3673
  • Quick Add on Quick Quotes and Appointments now adds eligible tire and catalog packages without requiring a vehicle TWHD-4387
  • Inventory Manager no longer prompts to save unchanged Pricing tab data TWHD-3130
  • Customer-specific pricing rules now apply when no default price level is assigned TWHD-3513
  • Auto-applied discounts now honor Allow Once per Invoice when multiple eligible packages exist TWHD-4437
  • Oil change packages now honor the package-configured oil quantity as the minimum billed quantity TWHD-4440

Purchasing and Receiving

  • A return order created from Unsold Purchases now moves to fully returned after it is processed once, and its returned quantities stay negative TWHD-4554
  • Canceling a new, unsaved Purchase Order now closes it without the lock-loss warning TWHD-4460
  • Calendar pop-ups now close when canceling or backing out of Inventory Receipt or AP Invoice transactions TWHD-4243
  • Great Plains return calculations now preserve the expected historical return behavior TWHD-4453
  • Vendor PO auto-replenishment now honors the location TimeZoneOffset for store-local scheduling TWHD-4475

Transfers and Sourcing

  • Copying a Service Request order now preserves transfer details for receiving transferred items TWHD-2827
  • The sending store’s transfer screen now shows the cost saved when the transfer was sent, for sent, in-transit, and completed transfers, instead of the item’s current cost TWHD-4180
  • Outside Purchase receive and cancel buttons now update correctly after a successful receive TWHD-4239
  • Replenishment searches in new purchase orders now load without freezing TWHD-4392
  • ASL inventory from wholesale locations now appears correctly in Retail transfer searches TWHD-4487

Inventory and Items

  • Service Request Add Selected Item modals now keep Cancel and Done visible for long item descriptions TWHD-4476

Other Integrations

  • The Cancel button on a service request now disables immediately after an Auto Integrate order is marked complete and assigned an invoice number, unless the user has the “Auto Integrate - Modify orders with Completed Repair Orders” access right TWHD-4516
  • The Auto Integrate Submission tab now opens without technical errors for Repair Orders with labor items, and submission stops with a clear message when a labor item has no Labor Operation code TWHD-4515
  • Viewing an enlarged historical inspection image from a Service Request no longer leaves TireWorks HD unresponsive after the image is closed TWHD-4213
  • Tire HQ integration now uses HTTPS endpoints and transport security for Retail and Wholesale order processing TWHD-4535

Messaging, Email, and Printing

  • Closing a Text window that was opened by clicking twice no longer leaves the screen greyed out TWHD-4804
  • Temporary Crystal Reports files created for Work Order and Quick Quote reports are now removed after the report is generated, printed, previewed, or closed TWHD-4501
  • Report Viewer Excel export options were restored TWHD-3935
  • Rapid SMS icon clicks no longer leave the home screen disabled after closing preview TWHD-4232

Setup, Users, and Access Rights

  • The default customer field in Manage Locations is now labeled “Default Customer” instead of “Default Customer ID” TWHD-4467
  • The Quick Quotes Comment column now renders consistently and stays visible TWHD-2953

Performance and Stability

  • The database upgrade no longer fails while applying the add-new-location stored procedure TWHD-4386
