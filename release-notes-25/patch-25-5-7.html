New in version 25.5.7

New in 25.5.7Everything through 25.5.7

Retail: 46 cases. Wholesale: 10 cases.

Retail

New System Settings

ASL Fetch Page Size TWHD-3722

Number of ASL locations considered for fetching ASL values of SKUs in a batch

Reorder Point Calculation Method TWHD-3672

Determines whether the reorder point calculation uses only Quantity on Hand (QoH) or Quantity on Hand minus Committed (QoH - Committed)

New Features

Tire and Parts Search

  • Standalone purchase orders now use the most recently selected line code from F2 catalog searches TWHD-3905

Customers and Vehicles

  • Quick Quote and Appointment workflows now prompt users to choose the correct vehicle when multiple customer vehicles match, preventing automatic assignment to the wrong vehicle TWHD-3944
  • Carfax and Archived Service History are now available from the Vehicle History tab in Customer Maintenance without opening a service request TWHD-3468

Accounting Integrations

  • QBO tax variance validation now detects and logs post-posting discrepancies without blocking integration TWHD-3900

Messaging, Email, and Printing

  • Service Request printing was overhauled to improve speed, consistency, and calculations across print paths TWHD-3967

Bug Fixes

Service Requests and Invoicing

  • Service Advisor remains accessible after invoicing an order without requiring users to log out and back in TWHD-4216
  • Service requests can no longer be finalized to a closed status without a valid invoice number TWHD-3989
  • Copied retail orders now use the current tax percentage for the selected tax schedule TWHD-3921
  • Fixed-price Road Hazard charges now remain intact when tire prices are changed on service requests TWHD-4174
  • Manage Special Programs now blocks deletion of questions linked to previous orders and shows a clear message when deletion is not allowed TWHD-2427

Tire and Parts Search

  • F1 Tire Search fitment results now refresh when changing vehicles with Add Vehicle, preventing stale fitment data TWHD-3945
  • Transfer search results now show QOH and Quantity Available consistently for both retail and wholesale source locations TWHD-3918
  • ASL Quantity in Tire Search now handles transient SQL timeouts with retry logic and clearer failure messaging TWHD-4175
  • ASLQty values now consistently display for all SKUs when searching by tire size only in F1 SKU search, with improved performance and reliability regardless of result set size. A new system setting, “Asl Fetch Page Size,” controls the batch size for ASL location queries TWHD-3722

Customers and Vehicles

  • Closing Customer Detail with no vehicle assigned no longer causes an Object Reference Error TWHD-4217
  • Changing the assigned vehicle in Appointments or Quick Quotes now refreshes VIN and YMME data for the selected vehicle TWHD-3943
  • Customer Vehicle Data checkboxes no longer close the pop-up window during service request entry TWHD-3630
  • Customer Pricing Rules now display scrollbars correctly so all pricing rules and columns remain accessible TWHD-4222
  • Customer Merge Replace now completes without CustomerVehicleData primary key errors and preserves vehicle data TWHD-3938
  • Cash Customers can no longer be manually selected in customer lookup workflows or have members added, while remaining searchable from Find Customer TWHD-3714

Payments and Cash Drawer

  • Canceling the Over/Short comment box on the Cash Drawer Adjustment tab now discards only unsaved changes while preserving saved comments TWHD-1097

Pricing, Packages, and Discounts

  • Package pricing calculations now match configured fixed prices and line-item totals without decimal precision mismatches TWHD-4245

Purchasing and Receiving

  • Partially received purchase orders can now be closed without database errors TWHD-4227

Transfers and Sourcing

  • Users with Sourcing - Transfer Request access can now create transfer requests for unavailable quantities and backorder them when allowed TWHD-4182
  • Retail users can now cancel transfer requests sourced from wholesale without a false externally locked error, and both sides stay synchronized TWHD-4173

Inventory and Items

  • Inventory Manager controls remain enabled after multi-record item searches, preserving Save, Move SKU, and Program Product Codes access TWHD-4225
  • Inventory quantities are now stored and displayed as accurate decimal values without floating-point precision artifacts TWHD-4172

Other Integrations

  • Inspection videos now render and play correctly within the Inspection Detail view TWHD-4207
  • TCS Inspect customer creation now assigns Customer Class and Department Code correctly based on customer type TWHD-4013

Setup, Users, and Access Rights

  • Manage window access rights are now consistently enforced across additional windows and tabs, including prompts and interactive elements TWHD-4011
  • Hidden user settings no longer create blank rows in the Manage Users User Settings list TWHD-3916
  • The Manage All access right now correctly shows the Manage menu for View access, hides it for None access, and removes the Edit option TWHD-3841
  • Access rights enforcement for Manage windows has been standardized so None, View Only, and Edit behave consistently TWHD-3389
  • Authenticated sessions no longer intermittently revert to the defaultuser profile, preserving correct user identity and access TWHD-4167

Wholesale

Bug Fixes

Sales Orders and Invoicing

  • Process Orders now detects insufficient inventory for ecommerce orders with Skip Qty Check enabled and routes them to backorders instead of Shipment Manager TWHD-4205
  • Wholesale invoices with split payment terms now integrate successfully when document IDs contain hyphens TWHD-4201
  • New Invoice discounts now calculate immediately when entered, with validation for invalid discount entries TWHD-2749
  • Sales order completion and modification timestamps now use each location’s local time instead of server time TWHD-2434

Purchasing and Receiving

  • Canceled Inventory Receipts no longer appear in the Add Items list when creating AP Invoices TWHD-3231
  • Inventory Receipt item costs now update in real time when Use Current Costs for PO Items is changed TWHD-2557

Transfers

  • Transfer order processing now creates only one transfer request per order and rolls back related records on failure TWHD-3928

Setup, Reports, and Access Rights

  • Configure Search Results now keeps Field Name and Header Text sorting aligned for invoice results TWHD-2916

Web Services

Bug Fixes

AMI/Mopar

  • AMI inventory availability now displays for each configured sales location and groups warehouse quantities correctly TWHD-4196
  • AMI-created retail orders now map Dealer Reference to the Customer PO field on TireWorks HD service requests TWHD-4197

TDWebservices

  • TDPurchaseOrder now enforces Skip Qty Check and Backorder Processing settings for inventory allocation and backorder calculations TWHD-3881
