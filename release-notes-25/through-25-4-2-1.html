All notes from the start of version 25 through this patch. The patch number beside each note is the first patch that shipped it.

Retail

New System Settings

Update Cost Upon QuickQuote Conversion 25.4.1.1TWHD-2638

Determines if and when the cost of items on a Quick Quote are updated upon conversion to a Service Request. “Zero Cost” will update any $0.00 with that item’s “Invoice” Default Cost. “Always” will update the cost of every item with their “Invoice” Default Cost, so long as it’s greater than $0.00. “Never” will leave all costs of items on a Quick Quote unchanged

New Access Rights

Appointments - Configure Calendars 25.4.1.1TWHD-3302

Controls a user's ability to access the "Configure Calendars" screen from the Appointments tab to view or modify calendar configurations

Item - Edit Average Cost 25.4.1.1TWHD-2779

Ability to edit the Average Cost from the Site Detail Tab on the Item Details and Manage Inventory windows

Item - Edit Last Cost 25.4.1.1TWHD-2779

Ability to edit the Last Cost from the Site Detail Tab on the Item Details and Manage Inventory windows

Service Request - Expired Discount 25.4.1.1TWHD-1166

Ability to retain expired discounts and coupons which were previously applied to a service request
