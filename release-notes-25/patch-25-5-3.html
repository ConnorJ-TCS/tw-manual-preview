New in version 25.5.3

New in 25.5.3Everything through 25.5.3

Retail: 16 cases. Wholesale: no targeted changes.

Retail

New Features

Service Requests and Invoicing

  • The DR Invoice job (mainoptionid 75) now uses processed start and end dates based on the last run timestamp instead of DR numbers, and a new table records each job run and its details for improved accuracy and compliance with Bridgestone requirements TWHD-3531

Transfers and Sourcing

  • The Sourcing Manager Transfer screen now displays a dynamic grid showing available quantities for each item at each Alternate Stocking Location, with improved usability for multiple items, horizontal scrolling, and corrected UI issues TWHD-3715

Inventory and Items

  • A new checkbox, “Allow User to Edit the Item Description on Service Requests (for California BAR compliance),” has been added to the Manage SKU Types window, and the related access right "Service Request - Item Description" now acts as an override, letting authorized users edit all item descriptions regardless of SKU Type settings TWHD-3780

Bug Fixes

Service Requests and Invoicing

  • Resolved an issue where converting a Quick Quote or Appointment to a Service Request in could intermittently fail with a Foreign Key constraint error related to the Customer Contact information TWHD-3775
  • Fixed an issue where updating the tire price on a service request would incorrectly set the associated road hazard price to zero; now, both prices remain accurate and the total reflects all charges as expected TWHD-3788

Customers and Vehicles

  • The Customer Details UI now correctly displays only bill-to addresses for the selected bill-to customer, preventing foreign key errors and ensuring users can complete orders even when bill-to and ship-to customers differ TWHD-3793
  • Pressing Enter in the Find Customer window for Copying Customer Rules now always triggers a customer search, regardless of prior SKU field input, and no SKU-related errors or pop-ups will appear TWHD-3615

Inventory and Items

  • Cycle Count processing now correctly sets the DateCompleted field on Inventory Adjustments when the "Auto Process Inventory Adjustment" system setting is enabled TWHD-3651

Messaging, Email, and Printing

  • TCS Inspect message timestamps in the Customer Communication / SMS Hub now correctly use the store’s configured local time zone, ensuring all messages appear in proper chronological order regardless of their source TWHD-3628
  • The "Preview" tab in the Send Email window now correctly displays large spaces and line breaks, ensuring the preview matches the formatting of the actual email sent to customers TWHD-1418

Web Services

New Features

TCS Inspect Service

  • The AppointmentList response now includes an appointmentDuration field for each appointment, allowing integrators to see the total duration directly in the response TWHD-3740
