New in version 25.4.3.1

New in 25.4.3.1Everything through 25.4.3.1

Retail: 7 cases. Wholesale: no targeted changes.

Retail

New System Settings

Inventory Receipt - Populate Quantity Received TWHD-3560

Controls whether the "Quantity Received" field on inventory receipts is populated with outstanding quantities from the PO or set to 0 by default

New Features

Pricing, Packages, and Discounts

  • Discounts and coupons can be limited to specific price levels or customers TWHD-1086TWHD-3354

Beta Issues

  • Vendor Credit integration now correctly retains the original sign of positive and negative quantity line items when syncing to all supported accounting systems, ensuring transaction totals match those entered in TireWorks HD TWHD-3588
  • The FSM (F6) window in QA Learn xR25.4.2.1 now correctly displays the Print, Cancel, and Done buttons, and all window contents are properly aligned with no overlapping fields TWHD-3583
  • Resolved an issue where creating a new customer after adding a vehicle to a cash customer during service request creation caused a foreign key error TWHD-3568
