New in version 25.4.3.2

New in 25.4.3.2Everything through 25.4.3.2

Retail: 9 cases. Wholesale: 1 cases.

Retail

New Access Rights

Credit Card Terminal "Do Not Ask Again" Selection TWHD-3644

Controls whether a user can view or edit the "Do Not Ask Again" option on the Credit Card Terminal Selection prompt and in the My Preferences > Credit Card Terminals tab

New Features

Setup, Users, and Access Rights

  • A new "Calendars" tab has been added to the Manage Users screen, allowing system administrators to configure, copy, and manage user calendars by location TWHD-3362

Wholesale

Bug Fixes

Sales Orders and Invoicing

  • Users can now open and interact with the AP Invoice window in Purchasing without encountering object reference errors TWHD-3567

Beta Issues

  • Fixed an issue where orders would close before payment and signature capture were completed when the “EnableApproval” setting was enabled; now, the order remains open and the user stays on the order screen until all payment and approval steps, including signature capture, are fully finished, preventing premature closure and ORE errors TWHD-3662
  • The "Inventory Receipt - Populate Quantity Received" system setting now also auto-fills the quantity received when adding items from search windows TWHD-3649
  • Users assigned to only one location can now log in and are always shown the IPOSPays terminal selection window, ensuring they can select a terminal and proceed with their workflow TWHD-3631
  • Users with EDIT rights to the "User Management - My Preferences" access right can now save changes to their own preferences without needing EDIT rights to "User Management." TWHD-3648
  • The signature background has been updated to white, ensuring consistent appearance across all printouts TWHD-3658
  • The CreditCardName field in iPOSPays Sale and Return transactions now correctly displays the card type from the response instead of the customer's name, improving transaction accuracy and reporting TWHD-3627
