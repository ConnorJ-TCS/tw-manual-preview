New in version 25.5.2

New in 25.5.2Everything through 25.5.2

Retail: 12 cases. Wholesale: no targeted changes.

Retail

New Features

Other Integrations

  • The ePower export stored procedures cusp_TCS_Customers and cusp_TCS_AllSkus have been enhanced to support per-customer and per-location export logic, using the new CustomerAddressECommerce table when the "ePower Home LocationId" system setting is not defined. Legacy export behavior is maintained when the system setting is set TWHD-3727

Bug Fixes

Service Requests and Invoicing

  • Road Hazard items can now be consistently added to service requests when configured, restoring expected RH functionality for users TWHD-3767

Tire and Parts Search

  • Sales tax is now correctly applied to catalog labor items added individually to a service request in ISE using the "Lookup" field, ensuring consistent tax calculation regardless of how labor is added TWHD-3777
  • Closing the Parts Lookup window in a Service Request using the “X” now properly clears the session, ensuring previous lookup results do not appear when opening a new Service Request TWHD-3768
  • The Customer Merge Utility in TireWorks HD v25 has been updated to resolve foreign key constraint errors, ensuring customer merges complete successfully and all associated vehicle records are moved without database issues TWHD-3738

Customers and Vehicles

  • Editing multiple customer addresses now correctly preserves all city and state fields after saving, preventing any data loss regardless of which address was last viewed TWHD-3787

Inventory and Items

  • The Inventory Account Mapping Window now displays tree node expand arrows correctly and includes a horizontal scroll bar at the bottom for easier navigation TWHD-3765
