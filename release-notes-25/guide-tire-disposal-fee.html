Retail - Tire Disposal Fee

A comprehensive set of features aimed at enabling stores to charge a tire disposal fee on tire packages, or to record that the customer declined it. Setup works the same way as Road Hazard and Nitrogen fees, one location at a time, with a fee item, pricing, and optional inventory tree mapping.

Tire Disposal Fee is available in TireWorks HD Retail 25.4 and later, with Quick Quote, Appointment, and Order Validation support in 25.5 and later. It is enabled on request through TCS Support. Until it is enabled, none of the Tire Disposal settings, buttons, or validation described here appear.

New System Settings

Include Tire Disposal on QQ and Appt screen

When enabled, the “Include Tire Disposal?” checkbox on the Tire Quote window is checked by default for Quick Quotes and Appointments.

Include Tire Disposal on Service Request screen

When enabled, the “Include Tire Disposal?” checkbox on the Tire Quote window is checked by default for Service Requests.

Tire Disposal Setup

A new Tire Disposal tab under Manage > Company Setup > Other Fees & Charges configures the fee for each location, with the same options and behavior as the Road Hazard and Nitrogen tabs. Configuration options:

  • Tire Disposal Active turns the fee on for the location.
  • Automatically Add Tire Disposal includes the fee in the quoted tire price on Tire Quote.
  • Taxable marks the fee as taxable for the location.
  • Use Inventory Tree Mapping limits the fee to tires in chosen manufacturers, submanufacturers, or classes.
  • Track Declined Tire Disposal records a declined fee using a Declined DISP Item, added to the order at $0.00.

The Tire Disposal Items grid sets the fee by price level, either as a fixed price or as a percentage of the tire price with a maximum, minimum, and rounding cutoff, along with the fee item and its GL account. Copy Tire Disposal Settings copies a finished setup to other locations.

Adding or Declining the Fee on an Order

Service Requests, Quick Quotes, and Appointments now show Add DISP and Decline DISP buttons on tire packages, next to the Road Hazard buttons. Add DISP adds the location’s Tire Disposal item at its calculated price, and Decline DISP adds the declined item at $0.00. The buttons appear only when Tire Disposal is active for the location and the package holds a tire that matches a Tire Disposal setting. Each add or decline is recorded for auditing.

Tire Quote

A new “Include Tire Disposal?” checkbox sits next to “Include Road Hazard?” on the Tire Quote window. When it is checked, packages added from Tire Quote include the Tire Disposal item, and the package preview updates as soon as the box changes. Its default follows the two system settings above.

Order Validation

Order Validation Setup has a new Tire Disposal row. For each order state, it can ignore the check, warn, or block saving when a qualifying tire package has neither the Tire Disposal item nor the declined item. When validation stops an order, Fix offers Add Tire Disposal and Decline Tire Disposal. The check is skipped on orders with a Goodyear or TreadNet special program, the same way Road Hazard is.
