Retail – AMI/Mopar Integration

A comprehensive set of features aimed at enabling the integration between TireWorks HD Retail and the AMI/Mopar.

New System Settings

AMI - Estimated Delivery Date

Select how the delivery day is determined for Inventory, Order, and Order Status Inquiry to AMI. Static options ignore the Location’s Cutoff Time and always return a set day, with the delivery time matching the Location’s Close Time. The Dynamic option checks the Location’s Cutoff; if the cutoff has passed, the next business day with operating hours is used, and the delivery time is set to that day’s Close Time. If the cutoff has not passed, today’s date is used with the Location’s Close Time.

New Access Rights

Customer Management - eCommerce Tab

Allow access to Customer Management - eCommerce Tab

AMI/Mopar Service Enhancement

The AMI/Mopar service has been enhanced to support integration with TireWorks HD for Wholesale-only, Retail-only, or combined deployments. For Retail-only implementations, it is necessary to set the “RetailOnlySetup” key to “TRUE”.

Introduction of eCommerce Tab

A new eCommerce tab is now available within the Customer Maintenance window to facilitate customer configuration for the AMI/Mopar API integration, consistent with existing Wholesale operations. Access to this feature is controlled by the “Customer Management – eCommerce Tab” permission.

Customer configuration procedures mirror those of the Wholesale functionality and enable users to specify essential eCommerce details including default sales locations, eCommerce UID, password, and other relevant settings.
