Web Services release notes

New Features

AMI/Mopar

  • Estimated delivery dates sent to AMI are now correctly converted to UTC using the “SQL Database Time Zone” system setting, ensuring accurate ETAs for customers and consistency across all deployment types 25.5.5TWHD-3471

QBO Webhook

  • Payload processing has been migrated to support the new CloudEvents format, ensuring continued integration and compliance with Intuit’s updated requirements. The update is fully backward compatible, and both legacy and CloudEvents formats are now supported 25.5.6TWHD-3958

eXceedService

  • An internal text message alert is now triggered when a Service Request is successfully created through the TDPurchaseOrder endpoint, ensuring staff are immediately informed with the correct Order ID and Customer Name formatting 25.5.4TWHD-3049
  • An internal text message alert is now sent to staff when a new QuickQuote is successfully created via the CreateNewQuickQuote endpoint, including the order ID and customer name for both household and business customers 25.5.4TWHD-3048

TCS Inspect Service

  • The AppointmentList response now includes an appointmentDuration field for each appointment, allowing integrators to see the total duration directly in the response 25.5.3TWHD-3740
  • The AppointmentList response now contains the "IsCustomerWaiting" field 25.4.1.1TWHD-3341

TireWorks HD Mobile

  • The “VIN Scanning” option, which is no longer in use, can be concealed using the config file setting “EnableVINScanButton” 25.4.1.1TWHD-2994
  • The Retail module of the Mobile site has been modified to accommodate EAN/UPC Mapping and Inventory Receipts, aligning its functionality with that of the Wholesale module 25.4.1.1TWHD-2924TWHD-2923

Bug Fixes

AMI/Mopar

  • AMI inventory availability now displays for each configured sales location and groups warehouse quantities correctly 25.5.7TWHD-4196
  • AMI-created retail orders now map Dealer Reference to the Customer PO field on TireWorks HD service requests 25.5.7TWHD-4197

eXceedService

  • Fixed an issue where concurrent appointment creation requests for different locations could incorrectly assign the same tax schedule 25.5.6TWHD-3697
  • The GetOrderStatuses API now correctly includes CustomerMemberId and CustomerVehicleId in its response when these values exist in the database, improving data accuracy for integrations and user workflows 25.5.5TWHD-3891

TCS Inspect Service

  • Users can now convert appointments using the TCS Inspect app regardless of whether the appointment is locked in the UI, resolving previous errors and ensuring smooth appointment conversion 25.5.5TWHD-3892

TDWebservices

  • TDPurchaseOrder now enforces Skip Qty Check and Backorder Processing settings for inventory allocation and backorder calculations 25.5.7TWHD-3881
  • The GetCustomerInvoices web service now returns only the requested invoice when an InvoiceID is provided, regardless of date filters, eliminating unrelated invoices from the response 25.5.6TWHD-3919
  • Tire line items with decimal quantities are now correctly added to Purchase Orders via eXceedPOInterface, using the floor integer value for tire items (SkuType = 0), while non-tire items remain unaffected 25.5.5TWHD-3652
