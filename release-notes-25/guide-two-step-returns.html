Retail – Two-Step Returns

A comprehensive set of features aimed at enabling new two-step returns.

New System Settings

Inventory Returns - Two-Step Workflow

When enabled, processing a return PO will not automatically generate or process a return Inventory Receipt or AP Invoice (Vendor Credit).

Disable Automatic AP Invoice Generation

Determines if AP Invoices or Vendor Credits are generated immediately upon processing an Inventory Receipt or Return. When enabled, Invoices and Credits will only be created when done so manually.

New Access Rights

Two Step Return Process - Return Button

Ability to access the Return button on the Inventory Receipt when the Two-Step System Setting is enabled.

Two Step Return Process - Credit Button

Ability to access the Credit button on the AP Invoice when the Two-Step System Setting is enabled.

“Return” and “Credit” Buttons

For Purchase Orders and Inventory Receipts that have been processed, a new "Return" button has been introduced to streamline return initiation. This feature is accessible within the Find > Purchase Order and Find > Inventory Receipt interfaces. Additionally, for Inventory Returns that have reached a "Returned" status, a "Vendor Credit" button is now available, enabling users to efficiently initiate credits directly from the return record.

Separation of Inventory Receipt/Return and AP Invoice/Vendor Credit Processing

With this release, a new setting has been implemented to enhance the processing of Inventory Receipts and Returns in relation to AP Invoice and Vendor Credit management. Previously, when the "Send AP Invoice" option under Manage Accounting Integration was active, the system would automatically generate and process an AP Invoice upon completion of an Inventory Receipt in TireWorks HD.

The newly added system setting, "Disable Automatic AP Invoice Generation," now removes the previous dependency on the Manage Accounting Integration setting. By default, an AP Invoice will be generated when an Inventory Receipt is finalized, regardless of the Manage Accounting Integration configuration. However, if the new setting is enabled, automatic AP Invoice generation is suppressed, allowing invoices to be created manually and linked to the Inventory Receipt as needed via standard UI workflows.
