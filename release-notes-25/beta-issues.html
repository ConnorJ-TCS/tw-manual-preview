Beta Issues release notes

  • Fixed an issue where orders would close before payment and signature capture were completed when the “EnableApproval” setting was enabled; now, the order remains open and the user stays on the order screen until all payment and approval steps, including signature capture, are fully finished, preventing premature closure and ORE errors 25.4.3.2TWHD-3662
  • The "Inventory Receipt - Populate Quantity Received" system setting now also auto-fills the quantity received when adding items from search windows 25.4.3.2TWHD-3649
  • Users assigned to only one location can now log in and are always shown the IPOSPays terminal selection window, ensuring they can select a terminal and proceed with their workflow 25.4.3.2TWHD-3631
  • Users with EDIT rights to the "User Management - My Preferences" access right can now save changes to their own preferences without needing EDIT rights to "User Management." 25.4.3.2TWHD-3648
  • The signature background has been updated to white, ensuring consistent appearance across all printouts 25.4.3.2TWHD-3658
  • The CreditCardName field in iPOSPays Sale and Return transactions now correctly displays the card type from the response instead of the customer's name, improving transaction accuracy and reporting 25.4.3.2TWHD-3627
  • Vendor Credit integration now correctly retains the original sign of positive and negative quantity line items when syncing to all supported accounting systems, ensuring transaction totals match those entered in TireWorks HD 25.4.3.1TWHD-3588
  • The FSM (F6) window in QA Learn xR25.4.2.1 now correctly displays the Print, Cancel, and Done buttons, and all window contents are properly aligned with no overlapping fields 25.4.3.1TWHD-3583
  • Resolved an issue where creating a new customer after adding a vehicle to a cash customer during service request creation caused a foreign key error 25.4.3.1TWHD-3568
  • Variance amounts are now correctly calculated and displayed in the Program Reconciliation Transaction window when Vendor Credits are generated manually 25.4.2.1TWHD-3477
  • Fixed an issue where clicking the “Item Detail” icon on the Service Request screen caused an Object Reference Error; the Item Detail window now opens without any error messages 25.4.2.1TWHD-3504
  • We corrected an issue where $0 Service Requests would show the “Invoice Order” button as disabled 25.4.1.2TWHD-3492
  • We corrected an issue where the F3 search window would fail to display ASL totals 25.4.1.2TWHD-3495
  • We corrected an issue which caused errors when attempting to process Transfer Requests through Sourcing Manager 25.4.1.2TWHD-3498
  • We corrected an issue which caused some item descriptions to fail to print on Transfer orders 25.4.1.2TWHD-3503
  • We have implemented safeguards and warning messages to help prevent sending or receiving transfers w/ $0 cost items 25.4.1.2TWHD-3502
