New in version 25.5.4

New in 25.5.4Everything through 25.5.4

Retail: 18 cases. Wholesale: 3 cases.

Retail

New System Settings

PDF Printing - Use Legacy PDF Rendering Method TWHD-3685

Indicates whether to use the legacy method for PDF rendering using Adobe Reader. (Required on some Windows 10 and earlier versions)

New Features

Service Requests and Invoicing

  • A new Auto Print Documents option has been added, allowing TCS Inspect PDFs to be automatically printed with the invoice, streamlining the process for service advisors and ensuring customers receive their inspection results without extra steps TWHD-3592

Transfers and Sourcing

  • Internal text message alerts are now sent to locations whenever the AutoReplenishment daemon runs, notifying staff of each purchase order or transfer created, including success or failure details TWHD-3050

Messaging, Email, and Printing

  • TireWorks HD now supports built-in and browser-native PDF viewing, allowing users to open and view PDFs directly in the application without needing to download files or use third-party plugins. Basic PDF navigation features are included, and a system setting has been added to govern if native or third-party PDF viewers will be used TWHD-3685

Bug Fixes

Service Requests and Invoicing

  • Fixed an issue where Service Requests have manually set tax schedules would lose their schedule assignment after being saved and reopened TWHD-3873

Customers and Vehicles

  • The Customer Deposit window now keeps the bottom toolbar (Print, Reverse, Refund) visible and accessible when "Credit Card on File" is selected, with scrollbars appearing automatically if needed to prevent content from being pushed out of view TWHD-3524

Pricing, Packages, and Discounts

  • The total package hours in Service Requests are now correctly calculated based on the actual hours set for each labor item, rather than being influenced by the quantity of labor items. This fix ensures accurate labor hour estimates and prevents scheduling or workload management issues TWHD-1753

Purchasing and Receiving

  • Vendor sync error logs for QBO integration now display specific error messages for each failed vendor, and batch success messages are no longer shown if any vendors fail TWHD-3800
  • Returns for non-inventoried items now integrate successfully. Users will no longer encounter missing account configuration errors when processing these returns, and inventory account increases are correctly relieved upon return TWHD-3855

Transfers and Sourcing

  • Fixed an Object Reference Error when clicking the Replenish button in the Transfers tab, ensuring the replenishment process now populates without errors and transfers can be processed successfully TWHD-3823

Inventory and Items

  • Validation has been added to prevent saving Tire SKUs in Manage Inventory without required Tire-specific information, ensuring incomplete Tire entries can no longer be created and users receive clear error messages when fields are missing TWHD-3712

Messaging, Email, and Printing

  • The Customer Deposit print preview email window now correctly prepopulates the customer's default email address, displays additional addresses in a dropdown, and prompts to save new addresses, restoring consistency with other email workflows TWHD-3426

Setup, Users, and Access Rights

  • Duplicate Access Rights in the Manage Access Rights window have been cleaned up, ensuring each permission now appears only once and eliminating confusion caused by legacy data TWHD-3680

Wholesale

Bug Fixes

Sales Orders and Invoicing

  • Fixed an issue where wholesale to retail transfers failed to invoice due to application timeouts and database locks, ensuring transfers now complete successfully and are properly linked between wholesale and retail systems TWHD-3862

Purchasing and Receiving

  • Fixed an issue where the "Submit PO" button on the Purchase Orders screen failed to send electronic purchase orders to third-party vendors, resulting in a null reference error TWHD-3614

Inventory and Items

  • Fixed an error that prevented users from saving new SKUs in Inventory Management TWHD-3847

Web Services

New Features

eXceedService

  • An internal text message alert is now triggered when a Service Request is successfully created through the TDPurchaseOrder endpoint, ensuring staff are immediately informed with the correct Order ID and Customer Name formatting TWHD-3049
  • An internal text message alert is now sent to staff when a new QuickQuote is successfully created via the CreateNewQuickQuote endpoint, including the order ID and customer name for both household and business customers TWHD-3048
