New in version 25.4.3.3

New in 25.4.3.3Everything through 25.4.3.3

Retail: 10 cases. Wholesale: 1 cases.

Retail

New Access Rights

Special Program: Service Request - Prod. Code TWHD-3608

Controls whether a user can edit the Prod. Code value in the service request or item detail window when a special program is assigned

New Features

Accounting Integrations

  • The QuickBooks Desktop integration no longer depends on the locationacct table for determining the unentered liabilities account; if not specified in the socket config file, the application now correctly falls back to the inventoryacct table, allowing users to manage integration settings without support intervention TWHD-3623

Other Integrations

  • The media viewer in TWHD Retail now displays all attached images and videos in a vertically scrollable layout, allowing technicians to easily review multiple media items per inspection while maintaining compatibility with legacy inspections TWHD-3482
  • TWHD Retail now fully supports the new TCS Inspect media format, allowing multiple images and videos per inspection, as well as new inspection metadata fields, ensuring inspections display complete and accurate information. Legacy image support remains for backward compatibility, and both new and old inspection formats are handled seamlessly. No data is lost when inspections include multiple media items or new metadata fields TWHD-3481
  • The inspection detail header in TWHD Retail now displays new inspection metadata fields (Inspection Started, Inspection Submitted, Total Inspection Time, Marked 'All Okay', and App Type), and the Qty column has been removed from the service list TWHD-3483

Bug Fixes

Inventory and Items

  • Fixed an issue where adding an item to an Inventory Receipt using F1 while the “Qty Received” field was active could cause an object reference error; the workflow now completes without error and remains stable regardless of the “Inventory Receipt - Populate Quantity Received” system setting TWHD-3695

Performance and Stability

  • Stored procedure parameter names in the retail synchronizer were reverted to their original values to restore compatibility with the Populator Service, preventing service outages and SQL exceptions for existing installations TWHD-3681

Wholesale

New Features

Accounting and Integrations

  • The QuickBooks Desktop integration no longer depends on the locationacct table for determining the unentered liabilities account; if not specified in the config file, the system now correctly uses the inventoryacct table instead TWHD-3625
