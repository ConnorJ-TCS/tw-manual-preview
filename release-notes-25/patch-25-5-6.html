New in version 25.5.6

New in 25.5.6Everything through 25.5.6

Retail: 34 cases. Wholesale: 6 cases.

Retail

New System Settings

ASL Fetch Page Size TWHD-3722

Number of ASL locations considered for fetching ASL values of SKUs in a batch

Transfer Pricing Source TWHD-3986

Determines whether transfer prices are derived from the sending location or the receiving location

New Access Rights

Inventory Receipt - Allow Duplicate Reference Numbers TWHD-3940

Controls whether a user can process an inventory receipt or purchase order with a reference number that has already been used for the same vendor

Service Request – Tire Quote TWHD-3843

Controls the user’s ability to access and use the F1 Tire Quote screen within the Service Request and related workflows

New Features

Service Requests and Invoicing

  • A new “View Time Log” button has been added next to “Actual Hours” in the Line Item Detail window. The Time Log Detail window displays technician name, start/end times (with local timezone), total time, and stop reason TWHD-2323

Pricing, Packages, and Discounts

  • A new "Transfer Pricing Source" system setting has been added, allowing dealers to choose whether transfer prices are based on the sending or receiving location, with the default set to receiving location TWHD-3986

Setup, Users, and Access Rights

  • A new access right, "Inventory Receipt - Allow Duplicate Reference Numbers," has been added to control whether users can process inventory receipts or purchase orders with duplicate reference numbers for the same vendor TWHD-3940

Bug Fixes

Appointments and Quick Quotes

  • The Appointments tab now correctly displays customer names in the appointment preview when only a first name, only a last name, or both are provided, ensuring all appointments show identifiable customer information TWHD-3994
  • The “Overtake Object Lock” access right is now correctly enforced in the Appointments tab, preventing unauthorized users from overriding object locks TWHD-3642
  • Printing the Appointments tab for days with no scheduled appointments now displays an informative message and automatically returns users to the Appointments tab, ensuring consistent and user-friendly behavior in both Detailed and Daily report views TWHD-3828

Service Requests and Invoicing

  • Quick Add oil package resolution now consistently loads motor oil specs and prompts users for oil capacity when needed, matching the behavior of the full Oil Settings flow TWHD-4015
  • Fixed an issue where rapidly closing and opening Service Requests could cause intermittent errors due to asynchronous cleanup, ensuring that only the intended Service Request is disposed and users can work without disruption TWHD-3993
  • Changing a Service Request’s special program to “None” now immediately refreshes and displays the correct customer credit limit, enforces proper credit limit checks, and prevents invoicing beyond allowed limits without requiring users to save, close, or reopen the invoice TWHD-3952
  • Order Totals rulers/markers now update their percentage values in real time after discounts are applied at the Service Request level, with improved GP calculations, accurate rounding to the nearest cent, disabled sliders, and a clearer price breakdown display TWHD-3760

Tire and Parts Search

  • ASLQty values now consistently display for all SKUs when searching by tire size only in F1 SKU search, with improved performance and reliability regardless of result set size. A new system setting, “Asl Fetch Page Size,” controls the batch size for ASL location queries TWHD-3722
  • Purchase order creation via ISE will no longer fail if a supplier returns a non-numeric value in the QtyAvailable field TWHD-3829

Customers and Vehicles

  • Changing the customer on an existing order with an attached vehicle now works as expected, including when creating a new customer during the workflow TWHD-3365
  • Customer-selected oil viscosity in Service Request vehicle Oil Settings is now properly saved and persists after closing and reopening, regardless of EPICOR recommendations TWHD-3874
  • When resolving an oil package for vehicles with no set oil capacity and multiple possible capacities, the selected capacity is now correctly saved and used for package resolution, ensuring accurate oil quantities. The package item’s default quantity is only used if no capacity is set, selected, or declared TWHD-4007

Pricing, Packages, and Discounts

  • Fixed an issue where viewing and exiting a Service Request line item without making changes could cause unintended price rounding TWHD-3863
  • Fixed an issue where package-restricted coupons were incorrectly removed when quickadded items within the package were modified TWHD-2620
  • Fixed an issue where inventory-restricted coupons were incorrectly removed when unrelated package items were modified TWHD-2860

Transfers and Sourcing

  • The Sourcing Manager transfer screen now ensures the "Back" and "Done" buttons remain visible and accessible at all times, regardless of window size or the number of transfer locations, allowing users to complete transfer sourcing without UI blocking issues TWHD-4047

Inventory and Items

  • Users can now enable or disable the “BAR Compliance” checkbox for SKU Types with a positive SkuType ID on the SKU Type screen, allowing proper configuration of this permission as intended TWHD-3949

Other Integrations

  • Purchase Orders in TireWorks HD now correctly reflect a failed or not processed status when USAF returns errorCode=fail TWHD-4014

Messaging, Email, and Printing

  • Appointments opened from Order History in Customer Maintenance now display in the correct Appointment UI, with all actions like print and save consistently reflecting the true order type and status TWHD-3954
  • Resolved a memory leak in report actions for Service Requests, ensuring memory is properly released after QuickVIN decoding, Carfax history retrieval, and repeated printing TWHD-3280
  • Fixed an error in the Audited Events report that occurred when unchecking users in the filter, allowing the report to run successfully and apply the selected user criteria without system errors TWHD-3803

Setup, Users, and Access Rights

  • The Manage Tax Details UI now correctly locks the Tax Detail ID, Tax Agency (QBO only), Tax Detail Type, and Tax Detail Percent fields for all accounting systems, preventing edits to these fields on existing Tax Details TWHD-3886
  • The TCS Inspect Password in the Manage TCS Inspect Settings window is now properly obscured in Company Settings, preventing it from being displayed in plain text TWHD-3754
  • Phone numbers are now consistently displayed in the (XXX) XXX-XXXX format across all relevant modules TWHD-3298

Wholesale

Bug Fixes

Sales Orders and Invoicing

  • Return invoices now correctly populate the SO_ORDER_ID in the Ws_Invoice table, ensuring header and detail lines are linked for accurate reporting and integrations TWHD-3424
  • Fixed an issue where invoices with percentage-based discounts in Wholesale were not matching totals between TireWorks and QuickBooks TWHD-1788

Transfers

  • Transfer order processing now creates only one transfer request per order and rolls back related records on failure TWHD-3928

Inventory and Items

  • The Invoice OP Sku details UI now matches the Sales Order workflow by displaying SKUs from both the OP Sku submanufacturer and the IC_Sku_Usercost table, and the grid includes vendor ID and reference number columns for consistency TWHD-3903
  • The prompt for vendor and reference number details for outside purchase SKUs now only appears when processing new invoices that will trigger Inventory Receipt and AP Invoice generation TWHD-3902

Web Services

New Features

QBO Webhook

  • Payload processing has been migrated to support the new CloudEvents format, ensuring continued integration and compliance with Intuit’s updated requirements. The update is fully backward compatible, and both legacy and CloudEvents formats are now supported TWHD-3958

Bug Fixes

eXceedService

  • Fixed an issue where concurrent appointment creation requests for different locations could incorrectly assign the same tax schedule TWHD-3697

TDWebservices

  • The GetCustomerInvoices web service now returns only the requested invoice when an InvoiceID is provided, regardless of date filters, eliminating unrelated invoices from the response TWHD-3919
